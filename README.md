# UPC Pocket

面向中国石油大学（华东）的非官方 Android 校园助手项目，以 [ZZUPocket](https://github.com/3beuml/ZZUPocket) 为参考底座。

## 先读这里

- [项目文档索引](docs/README.md)
- [UPC 官方入口清单](docs/upc/官方入口.md)
- [UPC 入口配置](docs/upc/official-entrypoints.json)
- [校园系统机制探索方法](docs/research/校园系统探索方法.md)
- [郑州大学资料归档](docs/archive/zzu/README.md)

当前分支仍保留 ZZUPocket 的包名及郑州大学业务逻辑。UPC 的功能完成情况以对应开发分支和带日期的复核记录为准；不能把上游已有功能或入口页面可访问当作 UPC 接入完成。

根目录 `官方入口.txt` 是本机原始材料，可能包含临时授权参数；项目文档和配置使用脱敏后的固定入口。
