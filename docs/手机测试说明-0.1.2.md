# UPC Pocket 0.1.2-preview 手机测试说明

安装包：`UPC-Pocket-0.1.2-preview.apk`（Android 12 / API 31 及以上，debug 签名）。
SHA256：`CB601CD82426BA99CDCE27177281CE61EEF613B32F3451EC59DAFD6F1EE059EE`

请优先覆盖安装旧版（0.1.1-preview），不要先卸载；这样可验证本地课表/日程/专注数据是否保留。签名证书与旧版相同（`CN=Android Debug`，SHA-256 `07aaae87...06281`），versionCode 已从 2 递增到 3。

## 建议验收顺序

1. 打开 App，确认旧课表/日程/专注记录仍在；进入「课表 → 课程表设置 → 上下课时间」，确认显示“共 13 节”，滚动能看到第 11–13 节。
2. 课表 → 右上“导入” → 选择 CSV（可先用 `课表导入模板.csv` 或自备脱敏 CSV）→ 预览 → 确认；再次导入同一文件应提示跳过重复。也试一次“从剪贴板导入”。
3. 更多 → 校园服务 → 空闲教室 → 选唐岛湾/日期/第 1、2 节 → 查询。应显示真实结果或明确错误，不能把失败显示成“全部空闲”。
4. 更多 → 校园服务 → 图书馆座位预约 → “使用学校统一认证登录”。用本人账号在官方 CAS 页面正常登录后：
   - 选馆区/日期 → 查询房间 → 打开房间 → 点绿色可用座位 → 选起止时间 → 二次确认；
   - 在“我的预约”核对是否出现；如出现“已预约”，再测试一次取消；
   - 若学校弹出图形验证码，App 应明确提示并停止，不应显示预约成功。
5. 更多 → 校园服务 → 唐岛湾电费 / 校园卡余额 → 查看微信兜底弹窗。本包没有正式微信 AppID，不应出现“微信直达”按钮；复制/分享到微信由你手动点击。
6. 在微信中打开学校页面时，如提示“无效 token/登录失效”，请从学校公众号服务菜单进入；这属于学校认证上下文，不是 App 能补的。

## 本版已知边界

- 图书馆登录后的真实预约/取消尚未由开发者在真实账号上验证；模拟器只验证到 CAS 登录页加载。请以你的真机结果为准。
- 微信 SDK 适配代码已接入，但没有正式移动应用 AppID，因此未启用直达；`sendReq` 成功也不等于目标页/学校认证成功。
- 电费/校园卡原生余额未完成：唐岛湾依赖微信 OAuth，校园卡裸链接返回无效 token；本版不显示零余额或假数据，不提供充值。
- 课表导出脚本 `tools/upc-schedule-export.user.js` 尚未在真实登录课表页端到端运行；实际 UPC CSV 表头也需脱敏样本核对。模板测试不等于学校格式已验证。
- 空闲教室/图书馆数据受学校页面与网络条件影响；失败时会显示错误，不会编造结果。

## 反馈时请提供

- 具体入口、操作步骤、看到的文字/错误提示（截图请先遮住姓名、学号、房间号、余额等个人信息）；
