# UPC Pocket 学校使用手册

UPC Pocket 是面向中国石油大学（华东）的非官方校园工具。本手册以 Android 版 2.1.0 为例，供学校业务部门、信息化人员和老师核对应用接入的服务及数据处理方式。 [项目发布页](https://github.com/dlam12138/UPCPocket/releases) · [2.1.0 开发与验收记录](design/2.1.0-update-plan.md)

## 服务范围

应用在设备上直接访问相应校园服务，学校系统及其服务平台负责身份认证、业务规则和结果。官网、学习平台及场馆公众号等入口由系统浏览器或微信接续。

| 业务 | UPC Pocket 中的操作 |
| --- | --- |
| 查询 | 查看本人课表、校园卡余额与流水，查询宿舍电量、空闲教室和图书馆座位。课表、石光和 e站通按只读方式接入。报名、签到及事项提交由对应学校平台办理。 |
| 图书馆选座 | 用户选定座位和时段、确认后，应用向对应座位系统提交。开放日期、可预约时段和预约结果以该系统为准。 |
| 校园卡充值 | 用户确认金额并点击充值后提交订单，付款在微信确认，随后核对学校订单状态与卡内余额。 |
| 体育馆和游泳馆 | 应用提供公众号名称及菜单路径。场次查询、预约和结果核对由微信内的学校预约页面处理。 |

[学校服务入口及来源](upc/官方入口.md)

## 账号和数据

- **认证与传输。** 用户主动保存时，应用用 Android Keystore 保护的密钥加密学校账密，并保存在本机。学校账号的保存状态与各业务的登录状态分别显示。学校统一身份认证使用 CAS 的 HTTPS 登录。校园卡余额和唐岛湾电量沿用学校现有 HTTP 查询接口，分别传输本人学号和楼栋、寝室号。
- **本机记录。** 课表与余额等部分查询结果保存在应用私有空间，待办、专注记录和个人隐藏座位偏好也保存在设备上。通过「首页 → 设置 → 学校账号 → 删除账号」可清除保存的账密、关联会话和个人缓存。本机待办与专注记录保留。
- **位置与诊断。** 地图在本机搜索和算路，实时导航按需申请前台位置权限。位置和导航进度在内存中处理。诊断在本机记录有限的运行状态，由用户决定是否导出和分享。

## 核对和反馈

1. 从发布页下载 2.1.0 APK，计算 SHA-256 并与同页 `SHA256SUMS.txt` 中的对应条目比对。在 Android 12 或更新系统上安装后，从「首页 → 设置 → 关于 UPC Pocket」核对版本。 [2.1.0 发布与校验文件](https://github.com/dlam12138/UPCPocket/releases/tag/v2.1.0)
2. 从「服务 → 官方网页」打开对应的学校页面，在「服务 → 校园通讯录」将单位、电话、地址及已关联的地图落点与学校公开信息比对。需核验受保护业务时，使用经授权的本人账号，以对应系统的记录为准。
3. 反馈时注明应用版本、校区、功能入口、实际表现和对应的公开信息来源。截图或说明请隐去学号、账密、验证码及个人业务记录。 [项目反馈入口](https://github.com/dlam12138/UPCPocket/issues)

## iOS 网页版

iOS 网页版是独立的静态站点。导入的学期课表、待办和专注记录保存在当前浏览器或主屏幕网页应用中。图书馆、空闲教室、校历和 e站通使用固定的官方入口，登录、预约与结果核对由相应学校或业务平台页面处理。

核对时，在 iPhone 的 Safari 打开部署后的 HTTPS 地址，可从「分享 → 添加到主屏幕」试用。首次联网打开后，可用演示课表检查导入和离线查看，再比对各服务的跳转地址。 [iOS 网页版操作和官方入口](web.md)
