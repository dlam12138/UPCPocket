# 0.1.7 校园卡余额改用学号查询

2026-10-28。依据用户提供的《0-石大校园卡余额查询实现方法.md》。这是对之前余额登录方案的纠正，不是对真实账号业务成功的宣称。

## 改动

校园卡默认页面改为输入本人学号，POST http://jhzf.upc.edu.cn:20081/wechat/callinterface/getCardInfo.html，表单 sno / xxbh=synjones / idtype=sno / id。无需先进入 mb-xyk 平台登录、微信或统一认证。

检查 retcode=0、恰好一张卡、返回 sno 与输入一致，严格解析 db_balance 和 unsettle_amount 的整数分值；分别显示校园卡余额与过渡余额，不相加，不用零代替错误。输入的 8–16 位数字只是当前客户端限制。

只保存学号、两项金额、时间到 noBackupFilesDir 私有文件，采用 AtomicFile 写入；未单独加密。进入页面先显示带时间的旧记录，点击查询刷新；失败不覆盖上次成功记录。输入学号改变但查询失败时明确旧记录属于原学号。页面可清除记录换号。此缓存不属于登录会话，清理方式为“清除饭卡记录 / 更换学号”。

仅新增 jhzf.upc.edu.cn 的明文网络许可，不全局放开 HTTP。该学校接口本身为 HTTP，学号和余额传输不受 TLS 保护。请求不主动携带登录 Cookie，不自动跟随重定向，限制超时及响应大小，不记录学号和学校返回原文。

图书馆保留；课表暂停。原平台流水入口标明尚未验证成功，作为单独尝试入口保留，不再阻塞余额主流程。用户提供的材料只证明余额接口本人实测可用，明确指出流水需要有效会话；本版没有实现材料提到的微信流水会话导入，也没有宣称流水已修好。

## 手机步骤

1. 覆盖安装 UPC-Pocket-0.1.7-preview.apk，保留已有数据。
2. 更多 → 校园服务 → 点击校园卡条目右侧打开图标，进入“校园卡余额”。
3. 输入本人学号 → 查询 / 刷新余额。不需要登录；不要点下面的尝试平台登录入口来查余额。
4. 对照官方余额与过渡余额；断网重试应保留带时间的上次结果。
5. 重新进入检查缓存；点“清除饭卡记录 / 更换学号”应清空。
6. 若失败，反馈界面错误提示及网络环境即可，不要发送学号、密码或未脱敏余额截图。

APK 的完整 SHA256 见同目录 UPC-Pocket-0.1.7-preview.apk.sha256。
