## 3. 布局与交互

### 3.1 顶栏与紧凑筛选

- 顶栏标题就是「空闲教室」。
- 校区：唐岛湾 / 古镇口两个 chip。
- 日期：显示 `yyyy-MM-dd 周X` 的按钮 → 原生 `DatePicker`；同一行提供前一天、
  今天、后一天快捷操作。
- 教学楼：滚动选择对话框（不是窄条 `DropdownMenu`）。列表随查询结果返回；
  首次加载失败或为空时，对话框提供「查询全部教学楼」恢复动作。
- 节次：
  - 上午 1–5、下午 6–9、晚上 10–13 三个快捷 chip；
  - 整组全选才显示选中底色；部分选中用短横图标提示，点击会补齐整组；
    已选摘要始终显示实际的连续节次（如“第 2、6 节”）；
  - 「自选节次」打开 1–13 精细多选弹层，有全选/清空/取消/应用；
    清空后「应用」禁用，页面查询按钮也禁用，不能空节次提交。
- 一个主按钮「查询空闲教室」；加载中显示进度并禁用筛选。
- 首次进入自动查询一次默认条件：唐岛湾、今天、上午、全部教学楼，用于加载结果和
  教学楼列表；之后筛选改动只更新条件，不发请求，必须点查询。

### 3.2 结果

- 摘要：`空闲 X / 全部 Y`、校区/日期/教学楼/节次、更新时间、状态；
  右侧「仅看空闲」开关（默认关闭，整个标签行可点）。
- 默认同时显示空闲与占用；组头显示“空闲 X / 共 Y”。
- 网格使用一个 `LazyVerticalGrid`，筛选、摘要、组头都是整行 span，教室格按
  `GridCells.Adaptive(96.dp)` 自适应；普通 360dp 手机 3 列，320dp/大字号自动减列。
- 教室格：房名最多 2 行（详情保留完整名称）、固定“空闲/占用”文字；
  最小高度 76dp，触控目标大于 48dp；空闲为温和青绿、占用为克制浅红/暗红，
  两套颜色都带文字，不依赖颜色区分。
- 点击教室弹出详情：完整房名、教学楼、校区、容量（未知显示“未提供”，不编 0）、
  该结果实际使用的节次、空闲/占用；没有预约按钮。
- 空教室目录显示“不能判断为全部空闲”；全部占用时仍显示占用格并提示；
  “仅看空闲”没有结果时提示关闭开关。
- 查询失败保留上次成功结果并明确标“旧条件/未更新”；条件改变但未查询时隐藏旧结果并提示；
  迟到请求用请求序号丢弃，不覆盖新条件。
- 没有 WebView、认证、预约、后台轮询；数据仍来自 `PublicFreeClassroomRepository`。

## 4. 数据语义

`FreeClassroomResult.rooms` 已包含学校返回的全部教室及 `occupied`：
`occupied` 表示所选节次中任意一节被占用；只有所有所选节次都未被占用才显示“空闲”。
本页没有另造接口，也没有把 `availableRooms` 当成全部目录。

- `rooms` 为空：合法空目录，不是“全部空闲”。
- `rooms` 非空但 `freeCount == 0`：全部占用，仍展示占用格。
- `rooms` 全空闲：全部格显示空闲。
- 仅看空闲：只过滤教室格，组头计数仍按学校返回的整组计算。
