# 0.2.7 小组件 2×2 与通透布局

校园卡和唐岛湾小组件默认尺寸由 2×3 改为 2×2。顶部保留标题与 48dp 刷新按钮，下方是脱敏学号或楼号/寝室号、主余额/剩余电量、绝对查询时间。过渡余额仍在 App 内显示，小组件只突出主余额。

## 外观与尺寸

- 两个 provider 的 targetCellWidth/targetCellHeight 都为 2，minHeight/minResizeHeight 为 110dp。旧的 180dp 最小高度在实测启动器中仍会要求 3 行，已修正。
- Pixel Launcher 选择页实际显示“2 wide by 2 high”；新添加的两个实例都是 452×588px、420dpi，约 172×224dp。
- 内边距由 14dp 改为 10dp，删除大块无效内容；楼号和寝室号各有独立字段，同一行优先给寝室号留空间。
- 旧背景约 85%–95% 不透明，现为约 50%–70% 不透明的斜向渐变，配白色细边框与半透明刷新按钮，壁纸明显透出。
- 这是半透明磨砂风格，不读取壁纸或截屏，也不宣称支持跨启动器实时模糊背景。
- 修复切换深色模式后时间颜色沿用浅色值的问题：RemoteViews 按宿主当前主题解析颜色资源，使用项目 minSdk 31 已支持的资源颜色 API。

- 浅色默认字号、深色 1.3 倍字号和浅色 2 倍字号截图均已查看。常规 2×2 下数值、单位、脱敏账号、房号和绝对时间可见；2 倍字号会省略楼号末尾的次要部分，但寝室号优先完整保留。

## 手机验收

1. 覆盖安装；删除桌面旧的 2×3 组件，再从组件列表添加新的 2×2（无需卸载 App）。
2. 在自己的壁纸上检查通透感与文字；必要时可自行拉大组件。
3. App 内成功查询一次后，在桌面点刷新；核对脱敏学号/寝室、元/度和查询时间。
4. 本轮没有重新查询学校真实本人目标；手机上的实际接口可达性、其它 OEM 启动器和任意极窄尺寸仍需本人验证。
