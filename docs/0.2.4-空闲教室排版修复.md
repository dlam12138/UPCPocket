# 0.2.4 空闲教室排版复核与修复

第四步的分组网格、快捷节次、日期选择器、教室详情及真实公开查询均保留。本次修复独立复核截图发现的问题：320dp、1.3 倍字号下日期只显示“2026-…”，统计被开关挤成“全/部”断字。

## 实现

- 日期使用完整 `yyyy-MM-dd`，与前一天/今天/后一天操作组按可用宽度换行，不压缩日期或降低字体。
- “空闲 N”“全部 N”分别作为完整统计项，与“仅看空闲”开关自然换行。
- 教室网格最小列宽同时考虑可用宽度与系统字号：96dp × max(1, fontScale)，保留系统字体缩放。
- versionCode 16，版本 `0.2.4-lightly-preview`；未改变查询协议、图书馆、余额、电费和专注功能。
