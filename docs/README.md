# 项目文档

当前版本为 **UPC Pocket 2.0 正式版**，用户已验收通过，M0–M5 已合入 main。安装包默认 R8 + 资源压缩，沿用兼容开发证书。发布范围、检查与限制见 [2.0 发布记录](releases/2.0.md)。

当前产品保留余额、电量、空闲教室、三个图书馆座位入口、课表、专注与三个桌面组件。研讨间功能已撤下；六入口研究与原始工程方案为历史参考，不代表现行产品范围。

M0–M5 文档保留各阶段的实施、真实证据与当时限制；其中“未发布/待评审”等文字是历史现场，以当前 README 与发布记录为准。
