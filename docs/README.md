# 项目文档

当前主线为 **UPC Pocket Lightly v0.2.7**。

[模块化与插件化工程方案 v0.1](模块化与插件化工程方案-v0.1.md) 的 M0 已完成工程实现、
自动化回归与模拟器覆盖安装/精简装配验证，记录见 [M0 执行记录](m0/README.md)；真实
校园接口、旧 Keystore 密文与完整组件数据刷新仍待具备条件后补验。

后续按 [统一账号与课表工程方案 v0.1](统一账号与课表工程方案-v0.1.md) 从 M1 推进：
M1 的本机加密账密、脱敏账号状态、代次与失效/清理基础已实现，记录见
[M1 执行记录](m1/README.md)；M2 的校园卡余额绑定、旧快照迁移与页面/组件/Worker 同目标已实现，
记录见 [M2 执行记录](m2/README.md)；M3 的课表真实 CAS 认证、学期/教学周查询、周网格、今日课程与
只读离线缓存已实现，记录见 [M3 执行记录](m3/README.md)。图书馆统一认证（M4）尚未实现。

M4 前置的六个图书馆/空间预约入口研究已完成，见
[图书馆与空间预约六入口接口研究](research/图书馆与空间预约六入口接口研究-20261103.md)。
研究覆盖公开前端/入口与既有来源核对，并用只读 UI 观察确认求是 `reservepc` 已在现有 Edge
加载研讨室列表；无 Cookie 的 303 探测不能代表现有会话不可用。另有用户授权的 26 条
`libseat` 只读 HAR，已确认 filters/floors/stats2/settings/announce/当前预约为空；该 HAR
不覆盖求是、nspace 或 Chaoxing。本机 Edge 没有 CDP 调试端点，未重启 Edge 或改调试配置，
因此求是 `reservepc` 的真实 XHR/HAR 仍待补。`libseat` 仍建议作为 M4 唯一现有范围，
`nspace` 与 Chaoxing 四入口分别需要独立业务验证或继续保留官方网页入口。
M4 功能实现仍暂停，等待用户确认范围。
M1 保存成功只表示“已保存，尚未验证”，不改变当前发布版对学校接口的接入方式。

页面安排、导航及视觉设计放在核心能力稳定后的 M5：M0 保持现有显示和交互等价，功能接入阶段仅增加必要界面，最后统一设计首页、栏目和入口布局。
