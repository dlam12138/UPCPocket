# 项目文档

当前主线为 **UPC Pocket Lightly v0.2.7**。

[模块化与插件化工程方案 v0.1](模块化与插件化工程方案-v0.1.md) 的 M0 已完成工程实现、
自动化回归与模拟器覆盖安装/精简装配验证，记录见 [M0 执行记录](m0/README.md)；真实
校园接口、旧 Keystore 密文与完整组件数据刷新仍待具备条件后补验。

后续按 [统一账号与课表工程方案 v0.1](统一账号与课表工程方案-v0.1.md) 从 M1 推进：
M1 的本机加密账密、脱敏账号状态、代次与失效/清理基础已实现，记录见
[M1 执行记录](m1/README.md)；M2 的校园卡余额绑定、旧快照迁移与页面/组件/Worker 同目标已实现，
记录见 [M2 执行记录](m2/README.md)。课表与图书馆统一认证（M3—M4）尚未实现。
M1 保存成功只表示“已保存，尚未验证”，不改变当前发布版对学校接口的接入方式。

页面安排、导航及视觉设计放在核心能力稳定后的 M5：M0 保持现有显示和交互等价，功能接入阶段仅增加必要界面，最后统一设计首页、栏目和入口布局。
