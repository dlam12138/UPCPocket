# 项目文档

GitHub 当前 Release 与 latest 为 **UPC Pocket 2.0.5 新版**（versionCode 26，`com.upcpocket.next`），标注“重大更新”，另有百度网盘备用下载。已安装新版 2.0.4 可直接更新；旧版 2.0.3 可继续使用、与新版并存，旧版数据无法迁移。下载与提取码见 [2.0.5 更新公告](releases/2.0.5-notice.md)，完整更新、校验值及验证范围见 [2.0.5 发布记录](releases/2.0.5.md)。历史发布见 [2.0.4](releases/2.0.4.md) 和 [2.0.3](releases/2.0.3.md)。

当前产品保留余额与本人流水、电量、空闲教室、三个图书馆座位入口、课表、待办、专注与三个桌面组件。2.0.4 已将按时段找座位与个人隐藏扩展到古镇口东区、求是，空闲教室增加卓越 A/B 分类。研讨间已撤下；历史研究不代表现行产品范围。

2.0.5 新增石光、e站通并完善流水、自动登录与诊断，已获用户验收并正式发布。最终签名 Release 四项真实账号只读验收已完成，详见 [2.0.5 更新说明](releases/2.0.5.md)。

M0–M5 文档保留各阶段的实施、真实证据与当时限制；其中“未发布/待评审”等文字是历史现场，以当前 README 与发布记录为准。
