## 约定

- 入口可访问、会话建立、数据读取、业务成功分别记录；HTTP 200 不等于业务完成。
- 不把账号密码、Cookie、Token 或未脱敏学生数据写入源码、文档、日志和测试样本。
- 不把第三方实现当作学校授权或官方契约；第三方线索必须用真实页面/账号重新验证。
