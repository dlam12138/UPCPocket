# 项目文档

开发/Agent 入口：[根 AGENTS](../AGENTS.md) → 受影响目录局部指令 → 按根任务矩阵读正文。当前知识从[架构](../ARCHITECTURE.md)、[内部契约](../API.md)、[贡献流程](../CONTRIBUTING.md)、[ADR](adr/README.md)进入；[Agent 手册](agent-native/README.md)说明显式加载、协作与维护，[兼容记录](agent-native/agent-compatibility.md)区分官方机制与实际验证，[建设报告](agent-native/2026-11-16-audit-and-delivery.md)记录审计、文件职责和未验证项。

这些是当前开发入口。下列阶段/候选资料保留当时状态；遇到旧路径、旧文案或“未实现”，先核对当前架构和正式发布记录，不能直接当迁移计划执行。原始总体计划保留原文。

**UPC Pocket 2.0.7**（versionCode 28，`com.upcpocket.next`）已于 2026-11-16 正式公开并设为 latest。下载提供 GitHub 和 gh-proxy，见 [更新公告](releases/2.0.7-notice.md)与[合并推广公告](releases/2.0.6-2.0.7-promotion.md)；原字节安装包、校验值及发布状态见 [2.0.7 发布记录](releases/2.0.7.md)。已安装新版 2.0.4–2.0.6 可检查更新或覆盖安装，2.0.7 测试版需手动覆盖；旧版 2.0.3 可共存，数据不迁移。此前 latest 的历史记录分别保留。

当前产品包括余额、本人流水与微信充值、电量、空闲教室、三个图书馆座位入口、石光、e站通、课表、待办、专注与三个桌面组件。研讨间已撤下；历史研究不代表现行产品范围。

2.0.5 新增石光、e站通并完善流水、自动登录与诊断，已获用户验收并正式发布。最终签名 Release 四项真实账号只读验收已完成，详见 [2.0.5 更新说明](releases/2.0.5.md)。

2.0.6 将今日课程移至首页，收紧待办与服务，重排空闲教室筛选和结果，优化课表、查询页与设置；图书馆登录默认折叠，学校账号状态简化为「已保存」。本人充值流程为「输入金额 → 点击充值 → 拉起微信」。用户已验收，开发侧真实只读准备和最终 Release 空账号/组件检查完成，真实下单、微信付款与到账未独立执行。需求见 [工程方案](design/2.0.6-ui-refresh.md)，历史证据分别见 [首批界面](releases/2.0.6-development.md) 和 [充值集成](releases/2.0.6-card-recharge.md)。

M0–M5 文档保留各阶段的实施、真实证据与当时限制；其中“未发布/待评审”等文字是历史现场，以当前 README 与发布记录为准。
