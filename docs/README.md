# 项目文档

当前主线为 **UPC Pocket Lightly v0.2.7**。

下一阶段首先执行 [模块化与插件化工程方案 v0.1](模块化与插件化工程方案-v0.1.md)：参考本地 Personal-Assistant，将现有功能拆成 Gradle 模块并通过插件契约装配，完成回归后再新增功能。

后续按 [统一账号与课表工程方案 v0.1](统一账号与课表工程方案-v0.1.md) 推进：本地加密保存学校账密、校园卡余额绑定账号、优先恢复课表，石光与 e站通后置。两份方案均尚未实现，不改变当前发布版的功能与隐私说明。

页面安排、导航及视觉设计放在核心能力稳定后的 M5：M0 保持现有显示和交互等价，功能接入阶段仅增加必要界面，最后统一设计首页、栏目和入口布局。
