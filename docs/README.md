# 项目文档

GitHub 当前正式 Release 为 **UPC Pocket 2.0.3**（versionCode 24）。另通过网盘提供 **2.0.4 新版**（`com.upcpocket.next`）可选独立安装；旧版可继续使用，不强制更新、不自动迁移数据。下载、提取码与校验值见 [2.0.4 安装公告](releases/2.0.4-notice.md)。历史正式版见 [2.0.3 发布记录](releases/2.0.3.md)。

当前产品保留余额与本人流水、电量、空闲教室、三个图书馆座位入口、课表、待办、专注与三个桌面组件。2.0.4 已将按时段找座位与个人隐藏扩展到古镇口东区、求是，空闲教室增加卓越 A/B 分类。研讨间已撤下；历史研究不代表现行产品范围。

M0–M5 文档保留各阶段的实施、真实证据与当时限制；其中“未发布/待评审”等文字是历史现场，以当前 README 与发布记录为准。
