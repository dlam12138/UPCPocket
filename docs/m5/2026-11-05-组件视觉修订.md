# 三组件视觉修订与精简 Release

2026-11-05 晚，基于用户对 2×2 课表/校园卡、刷新按钮和“小字”的反馈实施。本文是现行视觉与交付基线；此前 M5 文档中的“玻璃、半透明渐变、细描边、48dp 圆形刷新”等描述以本文为准。

状态：已实现、已构建、已在本机 `emulator-5556`（Pixel API 36，420dpi）验收；本地提交，不 push/merge/publish，待用户评审。

## 1. 设计基线

- 参考 Apple HIG 的克制层级：近实底、系统无衬线、少分隔线、少装饰，不用玻璃、渐变、重阴影、粗描边。
- 浅色表面 `#F7F7F9`，深色 `#1C1C1E`；主文 `#1C1C1E` / `#F5F5F7`，次文 `#6E6E73` / `#A1A1A6`，三级 `#8A8A8E` / `#8E8E93`，强调绿 `#1F7A52` / `#6FD3A4`。
- 统一 24dp 圆角、无 stroke；组件根布局不读壁纸，深浅色由资源限定符决定。
- 刷新：20dp 细线 `rotate-cw` 图标，44×44dp 透明点击区，仅按下时有极轻 ripple；不画圆盘/外框，不吞整卡点击。
- 三个组件共用标题 13sp、更新行 10sp、内容 12–13sp 的字阶；主数值仍保持大字号。数字只用有限分档，不做无限 autoSize。

## 2. 今日课表

结构：`今日课表`（13sp）→ 日期/状态（11sp）→ 主课（17sp，紧凑 16sp，最多两行）→ 时间（12.5sp/12sp）→ 地点（12.5sp/12sp，单行）→ 次课（11.5sp，单行）→ `HH:mm 更新`（10sp）。

- 日期与状态分开；日期不够时整行隐藏，不出现“11…”。
- 2×2 高 234dp（Pixel 实际网格）显示主课两行、时间、地点、一条次课和更新时间；高 160–180dp 的短卡退化为单主课，不硬塞次课。
- 4×2 显示完整主课、地点、次课起止时间与更新时间；不机械放大字体。
- 2×2 的次课只显示开始时间（如 `15:46 · 数据处理与实验设…`），把宽度留给课程名；4×2 才显示完整起止。
- 主课左侧不再放占宽的竖色条；改为日期行前 2×12dp 课程色 tick。这样 160dp 宽、1.0× 时也能完整显示 17 字课程名，同时保留课程色识别。
- 大字号（≥1.3×）隐藏 tick，优先保证日期/状态不被挤断；地点在 160dp×1.5× 时隐藏，避免被压成半行。
- 状态：未绑定、恢复中、清理中、未同步、非教学周、今天无课、缓存日期不符、刷新失败分别显示；未知不显示成“无课”。失败时保留旧值并在页脚标 `更新失败 · HH:mm`。
- 删除常驻“点按打开课表”小字；页脚只在有可靠时间时显示更新时间。

## 3. 校园卡 / 电量

- 校园卡：`校园卡` → 余额大数字 + 小“元” → `HH:mm 更新`。不常驻学号/账号，不再显示“学号…”占位；换号仍会立即撤下旧值。
- 电量：`唐岛湾电量` → 楼栋（次文，单行）与房间（主文）→ kWh 大数字 + 小 `kWh` → `HH:mm 更新`。保留“未设置房间/尚未查询/先在应用查询一次”等真实空态。
- 校园卡/电量数字按字符数分档，1.3× 以上字体再缩一档；`kWh` 比“元”宽，电量更早收缩，避免主数值被省略号裁掉。
- 标题 `paddingEnd` 收到 28dp，标题区可随字体换行；header 使用 `wrap_content + minHeight=30dp`，1.5× 字体不再上下裁切。

## 4. 自适应阈值

`TimetableWidgetLayout.forSize(widthDp, heightDp, fontScale)` 是唯一尺寸决策来源：

| 条件 | 结果 |
| --- | --- |
| `height < 150` 或 `fontScale ≥ 1.3 && height < 240` | dense |
| `width < 260` | compact |
| `!dense && ((wide && h≥200 && font<1.25) || (wide && h≥170 && font≤1.05) || (!wide && h≥215 && font<1.2))` | 次课 |
| `h ≥ (font≥1.3 ? 200 : 165)`，且不满足 `font≥1.1 && h<190`、不满足 `次课 && h<215` | 页脚 |
| `h ≥ (font≥1.3 ? 180 : 150)` | 日期/状态 |
| `h ≥ (font≥1.3 ? 175 : 155)` | 地点 |

实测：172×234 为 2 行主课 + 日期 + 地点 + 次课 + 页脚；160×160@1.0 为主课 2 行完整 + 日期 + 地点；160×160@1.5 为主课 2 行（省略号不可避免）+ 时间，地点按规则隐藏；360×234@1.0 为 1 行主课 + 次课完整；360×234@1.5 为 2 行主课、无次课、页脚保留。

## 6. 精简 Release

- `:app:assembleRelease` 使用既有 `isMinifyEnabled=true`、`isShrinkResources=true`；未升级 AGP/R8，未删除 keep 规则。
- 同一台机器、同一棵源码树：
  - debug：`app-debug.apk` **67,465,995** bytes，SHA-256 `39F3A5357368940C45B27A700CF7052C597E72CE66C30A96117D2812CD0B90EC`。
  - release：`app-release.apk` **4,642,177** bytes（约 4.43 MiB），SHA-256 `FE61368B88127FE092838F7D3A1601B8E8A60A60A10312DD9703DC57C44D3B3B`。相对 debug 体积减少约 93.1%。
- ABI：universal，含 arm64-v8a / armeabi-v7a / x86 / x86_64；没有另做 ABI 多包。
- 签名：仓库与本机均无 `keystore.properties`，release 使用标准 Android debug keystore（`~/.android/debug.keystore`）。证书 SHA-256 为 `07aaae87a235e3e1e99c364164a0a0774e27d8cbfd4bd68f32c03b31f1d06281`，与安装中的包一致，因此 `adb install -r` 可直接覆盖。它只能标为“**压缩 Release 构建、开发签名**”，不是生产/商店签名。
- 已核对 release manifest：应用自有组件只有 `MainActivity` 与三个正式 widget provider（AndroidX/WorkManager 组件仍在）；无 `com.upcpocket.app.debug`、`SyntheticTimetable*`、`WidgetPreviewActivity`。`aapt2 dump resources` 中也无 synthetic 的 layout/xml/string；debug 合成组件/预览 Activity 只在 debug source set。
- `adb install -r` 覆盖安装成功，版本仍为 `0.2.7-lightly-preview`（versionCode 19），数据保留；未 uninstall、未 `pm clear`。

## 7. 验收

- 单测：`core:designsystem` 6、`feature:card` 53、`feature:power` 27、`feature:timetable` 90、`app` 36，合计 **212 tests / 0 failures**（debug）。覆盖 160/172/180/234/360 宽、1.0/1.5 字体、标题 0 省略、主课最多 2 行、44dp 热区、24dp 圆角、深色资源、金额/电量分档、空态/离线/未同步/清理。
- 实测 172×234：主课完整 2 行、日期 0 省略、地点 1 行省略 3 字、次课 1 行、页脚 `HH:mm 更新`；160×160@1.0 主课 0 省略；160×160@1.5 主课 2 行、时间完整、地点隐藏、无上下裁切；360×234@1.0 主课 1 行完整、次课完整。
- Release 模拟器冒烟：三组件均由正式 provider 渲染；校园卡沿用旧缓存余额并显示 `元`；课表“未同步”状态正常；电量空态正常。
- 普通进程死亡：关闭 Wi-Fi/数据/飞行模式后 `am kill com.upcpocket.app`，不打开 Activity，点校园卡刷新；进程重建，`WidgetRefreshWorker` `SUCCESS`，旧缓存余额保留，页脚变为 `更新失败 · HH:mm`。未发起成功的真实学校查询。
- 点击：校园卡整卡打开首页；今日课表整卡打开课表 tab；两者均未被刷新热区吞掉。
- 设置页仍显示真实“已保存，尚未验证”状态；首页不再有长段免责声明。

## 8. 未验证 / 边界

- 未做真实学校登录、课程同步、预约/取消/签到；不把本轮视觉验收表述为校园接口验收。

- 模拟器为 Pixel Launcher 4×2/2×2 网格；用户截图中的 MIUI 桌面网格为 2×2 方形、尺寸/内边距可能不同，未直接在 MIUI 上复测。2×2 在 Pixel 上是 172×234dp 的非正方形网格，几何正方由桌面网格决定，应用不能强制。
