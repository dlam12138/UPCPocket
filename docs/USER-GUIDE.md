# UPC Pocket 用户使用手册

UPC Pocket 是面向中国石油大学（华东）的非官方校园工具。本手册以 Android 版 2.1.0 为例，底部提供「首页」「课表」「服务」「专注」四个入口。

## 安装和设置

1. 在 Android 12 或更新版本的手机上，从发布页下载 2.1.0 APK，按系统提示安装。已安装新版的用户可在「首页 → 设置 → 关于 UPC Pocket → 更新」检查更新。2.0.3 可与新版并存，首次使用新版时需重新设置账号、提醒和桌面组件。 [2.1.0 发布页](https://github.com/dlam12138/UPCPocket/releases/tag/v2.1.0)
2. 点首页右上角进入「设置 → 学校账号」。需要同步个人数据时，输入本人的学校账号与密码，再输入一次密码并点「保存」。页面显示「已保存」时，账密已加密存入本机。课表和图书馆等服务在使用时再进行学校认证。 [隐私与数据说明](PRIVACY.md)
3. 在「首页 → 设置」的「校园」区选择常用校区。空闲教室、图书馆和电费会优先打开所选校区，也可以在页面内临时切换。

## 查看课表和校园服务

打开底部「课表」，可切换学期和教学周，点右上角刷新。点课程可看地点、节次和时间。详情显示「在校园地图查看」时，可直接打开地图查找上课地点。已同步的教学周可以离线查看。首页显示当天的课程。

| 要做的事 | 怎么操作 |
| --- | --- |
| 查校园卡和充值 | 在首页「校园卡」查看本人余额，点「交易流水」查明细。点「充值」，选好金额后点「微信充值」，在微信确认付款。结果未明时先核对学校和微信账单，若页面显示「刷新支付状态」，也可用它查询原订单。 |
| 查宿舍电量 | 进入「服务 → 电费」。唐岛湾选择楼栋和寝室查询，古镇口打开学校网页。 |
| 找空闲教室 | 进入「服务 → 空闲教室」，选校区和日期。点上午、下午等预设时段直接查询，自选节次后点「查询」。临时占用以现场为准。 |
| 找图书馆座位 | 进入「服务 → 图书馆」，选唐岛湾、古镇口东区或求是。可按时段查找，也可在列表或座位图中选座。选好座位和时段后确认预约。提交超时或结果未知时，先核对对应系统的预约记录，再决定是否重试。隐藏座位只影响自己的页面。 |
| 查活动和事项 | 在「服务」中搜索「石光」或「e站通」。石光可查活动、学分学时和参与记录，e站通可查办事指南、本人待处理和在办。报名、签到和事项提交请在学校平台办理。 |
| 打开校历或校园网页 | 从「服务 → 官方网页」选择校历、教务系统、数字石大等入口。页面由系统浏览器打开。点图钉可固定到首页「常用服务」。 |

## 地图、通讯录和学习平台

- **校园地图。** 在「服务 → 校园地图」选校区、搜索地点，预览步行或骑行路线。允许前台定位并取得位置后，可点「开始导航」。古镇口西区以地点浏览为主，通行以现场为准。
- **校园通讯录。** 在「服务 → 校园通讯录」查找单位或办事窗口。点电话打开系统拨号器，点已关联的地址查看地图。
- **学习平台。** 在「服务 → 学习平台」打开知到（智慧树）、雨课堂、课堂派、石大云课堂或惟真学堂。「校外访问帮助」提供云课堂的 WebVPN 说明。点服务目录中「学习平台」旁的图钉，可将入口固定到首页。

## 体育馆和游泳馆预约

在「服务 → 校园生活」选择「体育馆预约」或「游泳馆预约」，点「复制公众号名并打开微信」。搜索「中国石油大学体育场馆」，在公众号的「场地预定」菜单中选择「场地预定」或「游泳馆预定」，再查看场次、提交预约并核对结果。游泳馆位于唐岛湾。常用校区为古镇口时，可从「首页 → 设置 → 校园官方网页 → 生活」打开游泳馆入口。

## 待办、专注和桌面组件

- 在「课表」页顶部的「日程待办」新建事项，可分别设置截止时间和一次性提醒。可在「首页 → 设置 → 应用 → 日程待办位置」将同一份待办移到专注页计时区下方。按系统提示允许通知。精确闹钟权限和后台限制会影响提醒时间。
- 在「专注」开始计时或补录记录，点「统计」查看历史。
- 长按桌面空白处，打开「小组件 → UPC Pocket」添加组件，也可从「首页 → 设置 → 桌面组件」发起添加。可选今日课表、校园卡余额、唐岛湾电量、待办清单和 4×4「本周课表」。课表组件需要先在应用内同步。本周课表按周日至周六显示课程，点整卡进入课表。余额和电量留意最近一次成功更新时间。

## 遇到问题

学校要求验证码或二次验证时，按页面提示前往对应学校入口。需要移除本机账密和关联缓存时，进入「首页 → 设置 → 学校账号」，点「删除账号」。待办与专注记录会保留。

反馈时提供应用版本、手机型号、Android 版本、操作步骤和提示文字。需要时可在「首页 → 设置 → 关于 UPC Pocket」主动导出诊断报告。分享前隐去账号、验证码和个人业务内容。 [问题反馈](https://github.com/dlam12138/UPCPocket/issues)
