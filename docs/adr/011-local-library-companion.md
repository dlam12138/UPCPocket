# ADR 011 · Mac 本机图书馆预约服务

- 状态为 Accepted，记录于 2026-11-21。
- 更新 [ADR 010](010-web-library-reservation.md) 的本机接入方式。

## 背景与决策

用户要求在已安装的 iPhone 模拟器 PWA 中完成选座和预约。Mac 回环上的同源服务默认启用唐岛湾站内预约，公开查询预览可以用 `--no-library` 启动。用户亲自在本机表单输入学校账号密码，服务沿用图书馆现有的官方 CAS 回调并核验本人。浏览器使用回环 Cookie 持有本机会话，学校业务令牌由 Mac 服务持有。验证码与额外验证提示前往官方页面处理。

PWA 显示房间、座位列表、真实坐标布局和学校提供的时段。服务端排队处理当前会话的请求，核对确认来源、当前登录身份和学校当前有效预约后，为本次提交编号持久登记防重标记再单次发送。上一笔待核对或已取消时，用户可以发起新的确认。提交后读取本人记录，按完整座位、日期和时段核对，一条学校记录最多确认一次提交。提交编号跨重启继续防重，同一时段过后释放待核对的选座字段。

## 取舍与影响

本机模式沿用图书馆业务回调，需要 Mac 持续运行。古镇口东区和求是使用超星座位系统，分别核验本人并使用独立会话与请求路径。新预约以最终占用复核和学校响应为准，这两馆的本人记录与取消在官方页处理。唐岛湾提供本人当前记录的站内取消，独立登记取消请求，预约与取消的结果各自核对。真机部署另需可信 HTTPS 和设备配对。 [隐私说明](../PRIVACY.md) · [Web 预约契约](../../API.md#web-图书馆预约)
