# ADR 007 · iOS PWA 静态部署与数据归属

- 状态为 Accepted
- 学校入口及部署方式后续由 [ADR 008](008-web-public-campus-data.md)更新。本文件保留首版实现的决策背景。
- 记录于 2026-11-19
- 依据为桌面《UPC Pocket · iOS 网页版开发计划与设计指南》、[官方入口](../upc/官方入口.md)、[ADR 002](002-account-generation-and-business-sessions.md)与 [ADR 003](003-data-ownership-and-schema-compatibility.md)

## 背景

首版要能从 iPhone 主屏幕打开，离线处理待办并恢复专注计时。现有学校课表可在官方网页使用，站内展示需要校方支持第三方 Web 接入及本人只读数据。

## 决策

- 将 [`web/`](../../web/) 作为独立静态应用，使用相对资源路径和哈希导航。Service Worker 按部署范围和版本缓存允许列表中的静态资源。
- 待办、活动专注和专注历史保存在 IndexedDB。到点或提前结束时，在同一读写事务内按会话 ID 生成历史并清除活动状态。静态缓存升级与本机数据升级分别处理。
- 用户主动点击后，通过顶层导航进入官方学校页面。校方负责认证、会话和个人页面；Web 首版使用官方入口，保留未来按校方授权接入的空间。

## 取舍与影响

静态部署让首版的本机功能无需维护账号服务或网络数据库。当前站点来源、安装环境和部署路径会影响记录及应用身份，故使用稳定的 HTTPS 地址；跨设备同步需要另行设计。服务端集成适用于校方明确提供并授权这类接入的情形，届时再决议维护与隐私边界。
