# ADR 008 · Web 站内公开数据读取

- 状态为 Accepted，记录于 2026-11-19
- 更新 [ADR 007](007-ios-pwa-local-data-and-school-links.md) 的公开服务与部署方式
- 本机个人课表的后续决策见 [ADR 009](009-web-semester-timetable-import.md)。

## 背景与决策

用户要求直接使用站内校园功能。两校区公开空闲教室查询返回数据，但未授权外站通过 CORS 读取响应。本机服务采用同源固定路径，沿用 Kotlin 查询字段与空闲交集语义。教务处校历通过公开目录在站内展示两个学期的原图，e站通通过公开目录和指南接口仅显示可公开读取的事项与说明。

课表以用户从本机选定的 iCalendar 文件生成周视图，保存在页面内存。自动同步需要校方提供受支持的 Web 授权、本人只读数据和会话规则。涉及预约和充值的 Web 接入还需要单次确认与操作结果核对。

## 取舍与影响

直连跨站接口依赖校方开放 CORS。固定路由服务可读取已公开且能核对来源的数据，代价是联网预览需要运行服务进程。静态缓存仍仅存放应用资源，公开查询结果与个人数据分别处理。部署时需在同一 HTTPS 来源同时提供网页与查询接口。
