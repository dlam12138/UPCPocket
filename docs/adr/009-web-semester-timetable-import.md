# ADR 009 · Web 学期课表本地文件导入

- 状态为 Accepted，记录于 2026-11-20。
- 更新 [ADR 008](008-ios-pwa-local-data-and-school-links.md) 的个人课表数据来源与存储方式。

## 背景

iPhone Safari 的实测记录显示，用户可在已经登录的学校课表页面运行 V3 书签，导出 19 周、零失败的 UTF-8 JSON。iOS「文件」App 能正常读取中文。Pocket 已有 `.ics` 周视图，但关闭页面后会失去预览数据。

## 决策

- 用户在 Pocket 所在的浏览环境主动选择 V3 JSON。浏览器严格校验 UTF-8、学期、完整周集合、日期和源课程。每个教学周以实际日期和节次生成，保留非连续节次、重叠和同名课次。
- IndexedDB 升级时增加学期课表存储，保留原有待办与专注数据。每个学年和学期的快照在提交成功后才更新，校验或写入失败保留旧快照。用户可清除选中的学期，`.ics` 继续作为临时预览。
- 课表文件与记录留在当前浏览环境。静态站点不设公开查询服务、账号服务或课表上传路径；个人课表流程不将学校账户、会话或课表发送到任何服务器。

## 取舍与影响

手动导入可离线查看完整学期。调课后需要重新导出并选择新文件。系统清除站点数据后可用原文件恢复。自动读取依赖学校提供正式的 Web 授权和会话规则。开发与本机操作见 [iOS 网页版](../web.md)。

## 粘贴导入补充 · 2026-11-20

Pocket 提供自包含的 Safari 书签脚本。用户一次性将脚本粘进 Safari 书签的网址，再在已登录的学校页启动它并确认导出。整学期成功后可以复制课表，随后在实际使用的 Pocket 页面或主屏幕应用里主动粘贴。粘贴内容沿用 V3 解析和整学期事务。文件入口继续可用。 [WebKit 剪贴板规则](https://webkit.org/blog/10855/async-clipboard-api/)

系统剪贴板可跨 Safari 和主屏幕应用传递文本。由用户发起的复制与粘贴保留了系统确认。通过 URL 携带课表会把个人内容放进浏览记录。跨窗口传递也无法在 Safari 和主屏幕应用之间共享存储。
