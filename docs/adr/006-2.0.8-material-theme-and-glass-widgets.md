# ADR 006：Material 3 主题与独立玻璃组件

- 状态：Accepted（2.0.8 外观决定）
- 日期：2026-11-18
- 关联：[ADR 005](005-2.0.8-toolchain-and-widget-state.md)、[用户验收与性能数据](../releases/2.0.8-development.md)

## 背景

用户在手机上报告 2.0.8 候选的液态玻璃主题卡顿，并确认此前修改的原组件已验收。原候选的同设备短采样中，玻璃模式 P95 为 550 ms，Material 3 为 18 ms。减少部分实时效果后的候选仍观察到卡顿。完整实时效果达到原主题流畅度，是保留 App 内主题的条件。

## 决策

应用使用 Material 3，保留配色、动态取色、深色模式和五 Tab 浮动胶囊。此前候选的 `ui_style` 键退出使用，同一份偏好文件继续提供其他设置。Kotlin、Compose、Room 与 R8 工具链按 ADR 005 保持。

校园卡、电量、今日课表、待办各保留原 Launcher Provider，再各增加一个固定静态玻璃背景的 Provider。原实例继续采用本机全局外观。宿主按业务类型聚合两种实例，按 Provider 选用背景并复用 renderer、动作与每类刷新任务。最后一个同类实例移除后取消该类任务。待办完成及电量刷新继续校验系统组件实例归属。

## 备选与取舍

共享背景或缓存画笔能省去部分重复工作。缩小渲染区域、降采样、改为静态材质或仅在按压时启用，都会减少原主题的实时视觉。现有设备证据支持采用 Material 3。桌面玻璃版沿用 RemoteViews，用固定资源绘制雾面和圆角内侧的弧形反光。组件底色略透，由 Launcher 与桌面合成。

全局外观配置会同时改变原组件，用户要求从桌面列表单独添加玻璃版。独立 Provider 让两种外观可以并存，组件身份也足以持久区分选择。

## 验证

验证重点是旧 Provider 身份、两种实例共享更新、单个版本移除后的调度、待办与电量动作归属，以及 Launcher 的添加、预览与桌面呈现。实际执行与证据见 [2.0.8 开发记录](../releases/2.0.8-development.md)。
