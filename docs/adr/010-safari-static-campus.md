# ADR 010 · Safari 校园服务、离线地图与本机日程

- 状态为 Accepted
- 日期为 2026-11-26
- 延续 [ADR 008](008-ios-pwa-local-data-and-school-links.md) 的静态站点设计与 [ADR 009](009-web-semester-timetable-import.md) 的课表导入流程。

## 背景

Safari 网页版需补齐常用校园服务、本机日程以及前台导航。已有 Android 校园地图、通讯录和教学楼图层可用于离线处理。校历原图公开可浏览，学校实时业务依赖各自的网络、登录或接口授权。

## 决策

- 保持静态 HTTPS 部署、原有 PWA 身份和 IndexedDB 名称。前端在 v3 增设个人日程对象仓库，保留已有课表、待办和专注记录。
- 地图、路网、通讯录和卓越楼图层以同源静态资源发布。搜索、渲染与算路在浏览器内完成。定位由用户主动启用，位置不持久化，离开地图或页面隐藏时停止。
- 常用校区、固定服务、排序和计时偏好保存在当前浏览环境。地图与校园服务采用稳定的哈希入口，普通打开和从课程、通讯录跳转共用页面。
- 校历维护静态学年索引，通过普通图片加载展示教务处原图。索引保留官方原文与栏目。学校查询、认证、预约和支付走固定官方入口。
- 应用和自带校园数据进入 Service Worker 缓存。学校网页及校历原图由其各自来源提供，个人内容不进入静态缓存。

## 影响

部署只需发布 [`web/`](../../web/)。校历索引和随站数据通过仓库更新。校园路线取决于已录入的道路和入口，前台定位取决于 Safari 权限与设备。个人记录与偏好留在各自浏览环境，系统通知或跨设备同步需要另外设计。
