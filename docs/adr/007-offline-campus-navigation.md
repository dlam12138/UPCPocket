# ADR 007 两校区离线校园地图与前台导航

- 日期 2026-11-19
- 状态 Accepted，开发实现的现场通行与入口仍待验收。

## 背景

用户确认沿用点位预览的道路底图，把参考图里的地点叠加到原地图，并完成类似主流地图的校内步行、骑行和实时引导。最初计划比较百度和高德的算路与导航接口，需等账号授权、平台许可、SDK 实测和现场验证。校内导航同时受校园细路、楼门位置和实际通行规则影响。

## 决策

在独立 `feature:campusmap` 中使用随应用提供的 OSM 道路与建筑几何，通过现有 UPC Pocket 设计呈现地图。按图数据建立校内路网，在设备本机生成步行和普通自行车候选路线。当前位置由 Android 前台定位提供，走偏时根据当前可信的位置重新算路。路线时间按出行方式估算，候选数量由各校区实际连通路网决定。

唐岛湾和古镇口分别提供校内地图。古镇口东区可在已录入的校内道路上算路，西区公开数据中只有少量连通道路，目前尚不足以支持实用的楼栋间导航。地图优先提供地点浏览，并在缺少连通道路时显示无可用路线。西区可用导航依赖经核实的校园路网，或通过现场验收的授权地图服务。

2026-11-20 核对唐岛湾参考图点位。7 个运动场地的位置与学校资料及 OpenStreetMap 地块相符。北门西侧排球场、工科楼北侧两类球场、多媒体学习中心和研究生公寓南侧网球场核实到所在区域，路线可规划至就近道路。 [体育教学部场馆统计](https://sports.upc.edu.cn/7677/list.htm) · [学校校园平面图](https://upce.upc.edu.cn/2018/0404/c8300a143081/pagem.htm) · [学校考点图](https://io.upc.edu.cn/kdjs/list.htm)

旧「足球场南侧网球场」坐标落在五人制足球场内，已撤销标记。学校列出的看台东侧网球场可搜索，独立坐标待核。北门西侧网球场的点位落在已有网球场轮廓内。 [原坐标所在足球场](https://www.openstreetmap.org/way/934524981) · [北门西侧网球场](https://www.openstreetmap.org/way/934524993)

19 个同楼服务或机构的楼栋依据公开目录核对。生活网点采用后勤指南中的名称，保留原点位 ID。12 号公寓的指南条目为综合维修店，改衣业务待核。14 号公寓邮政快递网点有招租记录，营业状态待核。路线按所在楼栋及其可用入口规划。地图资产按点位保存来源和核实范围。 [新生后勤服务指南](https://hqc.upc.edu.cn/2026/0904/c22148a499027/page.htm) · [服务网点招租公告](https://gzc.upc.edu.cn/2025/1210/c22664a479551/page.htm) · [中国银行网点](https://www.boc.cn/sourcedb/operations2021/406/608/610/index_124_1.htm) · [学校通讯录](https://csun.upc.edu.cn/19487/list.htm)

唐岛湾楼栋入口来自 2026-11-20 的用户地图标注。按底图轮廓微调到楼外，入口名称与编号供数据核对。86 个入口记录了通往现有步道路网的短连接，连接线经过建筑轮廓检查。体育馆东南门、文理楼西南门和讲堂群西北门保留点位数据，等待补录步道。入口实际开放情况待现场核实。 [学校校园设施说明](https://cie.upc.edu.cn/admission_cn/xysh1/xyss.htm)

地图、地点搜索、路线预览和引导显示楼栋或地点名称。路线按当前出发位置与出行方式比较已接路的入口，偏航重算优先继续前往原入口。步行路线的终点是选中的楼外入口。骑行路线到附近可骑行道路，再提示步行前往目的地。

开始导航后以最新可信定位为起点。手选起点用来预览路线。导航中根据定位沿路更新剩余路线，确认偏航后从新位置重新规划并继续引导。

定位匹配保留距离与行进进度范围，设备提供可信的移动航向时，用它区分接近的候选路段。小角度转向会提示左前方或右前方。

唐岛湾的设备位置在楼内且附近没有可用道路时，若能明确匹配该楼及已标注的入口，路线可从入口附近适合当前方式的楼外道路开始。导航立即进入跟随，楼内提示从楼门走到室外，出楼后根据位置自动衔接或重新规划。

服务目录及首页固定共用同一插件路由。课表详情仅通过宿主向活动地图插件交接当前点选的地点文字。定位、算路、路线进度和地点选择均在本机内存处理。

地图保持正北朝上。指南针在地图前台启用 Android 旋转矢量传感器，按屏幕旋转和校区磁偏角校正方向。传感器不可用时显示地图北向标记。实时引导仍以设备位置及其精度为准。 [Android 旋转矢量传感器](https://developer.android.com/develop/sensors-and-location/sensors/sensors_motion#sensors-motion-rotate)

## 备选和影响

百度与高德 SDK 可提供在线地图服务、路线与诱导，接入需要核对授权与数据处理。当前实现沿用已确认的底图，降低对联网、平台密钥和第三方 SDK 的依赖。地图更新随应用数据更新，路网修补、校门验证和现场验收由项目维护。

首次现场验收仍需核对常用楼门、步骑道路是否能走、古镇口两区的覆盖，以及步行和骑行的跟随定位、转向、偏航重算和到达。测试结果需区分本机算路与现场通行。

公开地图与派生路网数据使用 ODbL 1.0，地图页保留署名。随应用分发的 [校园地图数据](../../feature/campusmap/src/main/assets/campus_map.json) 内包含来源和许可元数据。 [OpenStreetMap 数据许可](https://www.openstreetmap.org/copyright) · [原导航开发计划](../design/2026-11-19-campus-navigation-implementation.md)
