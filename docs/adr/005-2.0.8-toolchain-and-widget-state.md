# ADR 005：2.0.8 工具链、截止迁移与桌面状态边界

- 状态：Accepted（工具链、待办和桌面数据边界）。应用主题与玻璃入口的决定由 [ADR 006](006-2.0.8-material-theme-and-glass-widgets.md) 取代。
- 日期：2026-11-17
- 关联：[ADR 001](001-module-and-plugin-boundaries.md)、[ADR 003](003-data-ownership-and-schema-compatibility.md)、[2.0.8 总计划](../design/2.0.8-update-plan.md)

## 背景

PR #9 使用 Backdrop 1.0.6、Shapes 1.2.0 及 Kotlin 2.3.10 / Compose 新版。原 AGP 8.7.3 的 R8 不能作为 Kotlin 2.3 的受支持基线；直接保留原 AGP 或跳过元数据检查不能满足候选的发布要求。本轮还新增待办独立截止与桌面操作，需要在升级 Room 时保留已有任务、提醒及专注数据。

## 决策

将构建基线调整为 AGP 8.13.2 / Gradle 8.13、Kotlin 2.3.10 / KSP 2.3.6、Compose BOM 2026.02.01，采用 Room 2.8.5。AGP 8.13.2 内置支持 Kotlin 2.3 的 R8 8.13.19；仍为 JDK 17+、minSdk 31、compileSdk/targetSdk 36。保留 Navigation Compose、手动 AppGraph、RemoteViews 与现有模块方向，不迁移 AGP 9、Hilt、Navigation 3 或 Glance。不导入候选的四项全局 Lint 禁用，也不关闭 Kotlin 元数据/R8 校验。实际依赖解析、迁移、构建与设备验证范围集中记录于开发记录，不以采用版本代替验证结论。

应用内玻璃使用固定 Maven 依赖和 `core:designsystem` 适配，支持 Material 3 切换；风格切换保持内容 composition 位置，不能销毁导航或编辑状态。平台简化与无可采样背景时的清晰回退独立验证。桌面组件继续 XML RemoteViews，仅提供本机静态材质，不读取壁纸或获取屏幕内容。

2026-11-17 后续用户验收报告玻璃卡顿，同模拟器短采样也显示原玻璃路径明显慢于 Material 3。采用轻量材质收敛：普通卡片/面板绕过常驻逐卡滤镜，重复图标按钮和筛选项保留按压高光及反馈；Dock 直接使用环境背景，移除导航内容的整页采集。保留圆角、着色、高光、点击反馈及重点控件交互折射。代价是普通卡片不再常驻真实模糊与透镜边缘，Dock 不再折射滚动正文；不增加设置或共享预模糊管线。绘制对象缓存不能证明帧率改善，新候选须按相同短脚本与 Material 3 复验，结果及设备局限见开发记录。

待办 `upcpocket-todo.db` v1→v2 使用显式 `ALTER TABLE todo_tasks ADD COLUMN dueAt INTEGER`；旧任务 `dueAt=null`。截止与提醒独立，不从提醒推导截止，不因设置截止申请通知或精确闹钟权限。保留旧字段、任务 ID、revision、数据库文件名和 v1 schema 原字节。focus 的独立 v1 数据库及停用课表兼容表保持不变；本决定对 ADR 003 的 todo v1 现状作后续扩展，不改写其历史记录。

桌面完成动作复用待办服务的条件更新，校验当前包显式组件、widget 归属、完整 taskId、revision 和目标状态。只有框架填入勾选值的 PendingIntent 可变，身份字段纳入稳定 Intent 身份以免新 extras 重绑旧动作；新建和普通导航保持 immutable。所有存储变化经窄回调重绘实例，截止与午夜只排本地任务，不触发学校网络。

四类组件的全局外观由宿主长期偏好保存，并向 renderer 注入通用外观值；不存入瞬态 WidgetStateStore，也不与余额、课表或待办快照混合。外观更改仅本地重绘，不重置联网/周期调度；校园卡仍走既有账号代次与发布屏障。

## 备选与取舍

只合 #8 并弃用 #9 无法满足本轮玻璃需求；保留旧工具链并自行重写玻璃管线会增加维护面。AGP 9 带来与需求无关的迁移。选用受支持的 AGP 8.x 小范围升级，代价是重新验证构建、R8、Lint 与 Room/KSP；依赖配置生效不等于验证通过。

把提醒时间直接展示为截止会改变数据语义；清库或改数据库名则丢失本机任务。每实例组件外观还需要实例恢复/删除迁移，本轮采用全局偏好以避免新增不必要状态。
