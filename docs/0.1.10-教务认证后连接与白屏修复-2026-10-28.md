# 0.1.10 教务认证后连接与白屏修复

## 问题与证据

CAS 已认证后，WebView 访问教务主页 `/jsxsd/framework/xsMainV.htmlx` 出现 `ERR_CONNECTION_RESET`；同设备原生 HTTPS GET 使用 App 自己的业务会话可返回正常 HTML。因此本次不要求用户提供密码，也未重新输入账号密码。

页面能够加载后仍白屏，是主页及菜单动态创建的 iframe 高度为 0。只设置 body 的 min-height 不能修复后续菜单窗格。

## 改动

- 仅教务导入 WebView 使用受限的原生 GET 传输，覆盖教务页面与资源；Cookie 按请求 URL 从 App 自己的 CookieManager 获取和更新。
- 范围限定为 `jwxt.upc.edu.cn` 默认端口与 `/jsxsd/` 路径；保留平台 TLS 校验，不将业务 Cookie 发送到其他域名。不代理 CAS 密码 POST。
- 限制超时、资源大小、重定向，保留资源字节、MIME、字符集，处理 gzip；错误不包含票据、Cookie 或响应正文。
- 对教务主页中已塌陷的可见同源 iframe 补像素高度，并监听菜单新增/显示的窗格。正常大小和隐藏窗格保持原样。
- 用户仍须自行登录并进入“学期理论课表”，再点击“读取当前页”。不自动导入课程。
- 版本为 code 11 / `0.1.10-preview`。图书馆、校园卡和电费业务未作功能调整。

## 实际验证

- `:app:assembleDebug :app:testDebugUnitTest :app:lintDebug` 成功。
- 451 项测试、43 类，0 失败、0 错误；lint 0 errors、70 warnings、8 information。
- 新增真实本地 HTTP 传输测试，覆盖 Cookie、重定向、跨域拒绝、gzip、二进制、字符集、错误状态与大小限制。
- Android 36 模拟器覆盖安装成功，已有登录会话仍可使用。通过 App 导入入口进入教务主页，无手动注入修复脚本；主页 iframe 高度 680px。
- 在已安装 App 中点击官方“学期理论课表”菜单，动态 `/jsxsd/xskb/xskb_list.do` 页面完成加载，高度 680px，内层可见 iframe 高度 680px，未观察到 `ERR_*` 错误。
- 只检查页面路径、加载状态和布局统计；未保存学生 DOM、课程记录、Cookie、票据或账号密码。

以上证明已修复复现出的连接和外层/动态窗格白屏；尚未验证选择实际学期后的课程完整显示、读取预览及最终导入，不将其标为完整实校导入成功。
