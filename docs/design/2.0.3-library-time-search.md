# 图书馆按时段找座位与个人隐藏：实施设计

日期：2026-11-07。用户已验收 `6721565` 的 2.0.3 整页滑动/胶囊候选，并授权设计及实施 [Issue #1](https://github.com/dlam12138/UPCPocket/issues/1)。本轮基于该提交，保留已验收能力；没有发布、合并或真实预约测试授权。

## 1. 产品范围

本轮先在**唐岛湾 libseat** 落地 Issue 的两个功能：按时段找座位、个人隐藏座位。两者都放在现有房间页，不增加首页入口、设置目录或底部标签。超星已有按时段查询的独立协议，本轮不套用 libseat 路径、不重做超星。

目标是让用户回答“我这段时间能坐哪里”，同时保留原先按座位选择时间的流程。简单、短文案、沿用已验收的 Compose Material 3 视觉；不新增 UI 框架、字体或装饰依赖。

## 2. 房间页结构

房间页顶部保留返回、房间名称、馆区与日期。下方放两段切换：`按座位选 / 按时段找`，首次进入默认按座位选。

按座位选保持现有座位图与时间选择。按时段找在同页呈现如下结构；下列内容仅是布局示意，不是学校实际数据：

```text
‹  三楼 A 区                         ⋯
   唐岛湾 · 11 月 7 日

       按座位选       [按时段找]

   开始时间                 结束时间
   [14:00 ▾]              [16:00 ▾]
                 [查找座位]

   已找到 18 个                 隐藏 2

   ○ 001                           ⋯
   ○ 006                           ⋯
   ○ 012                           ⋯
                   加载更多

   已选 006 · 14:00–16:00 · 2 小时
                              [确认预约]
```

- 页面左右边距 16dp、区块间距 12dp；控制区沿现有 surfaceContainerLow、16–18dp 圆角，结果是紧凑列表/弱分隔，不把每条结果做成大卡片。
- 标题沿现有 titleSmall/titleMedium，正文沿 bodyMedium，时间使用清晰对齐的现有数字样式；不另加展示字体。
- 候选行至少 56dp，可点击区域至少 48dp。座号突出，单选标记与更多菜单分开。配色/间距随现有主题，不硬编码浅色白底。
- 仅展示真实返回且已验证语义的座位设施标签；缺失即不显示，不将缺失解析成“无电源”。不增加无数据支持的安静度/日照排名。
- 底部复用现有选择摘要与确认按钮。房间是二级页，不显示主导航胶囊。底栏、键盘与系统导航区按现有 Insets 规则避让。
- 长标题、窄屏、1.5× 字体允许自然换行，时间控制可改为上下排列；不压缩文字或用省略号截掉起止时间。

## 3. 时间输入与查询触发

- 日期只来自学校现有可预约日期，不增加任意日期范围。开始/结束用系统风格时间选择器，明确 HH:mm。
- 初始不自动填一小时或虚构学校开放时间：显示“选择开始 / 选择结束”；开始和结束完整、同日且开始 < 结束时才可查找。
- 不把 UI 的 30 分钟间隔当作学校规则。选择器允许分钟输入，具体可约性以学校结果与该座位时间选项为准；本轮不支持跨午夜或自行解释 `now`。
- 点击“查找座位”才联网，不因拖动时间、切模式或列表重组反复查询；无轮询、不同时扫描各房间。
- 会话内可保留上次输入的时段。更换房间/日期/馆区后清空候选、已选座位、分页和最终可提交状态，用户再次查找。切换模式不得带入另一模式的旧确认状态。
- 查找中可以取消或更改条件；旧请求取消并按查询代次隔离，不能覆盖新条件。再次点击同一在途查询不重复发起；查询完成后可主动刷新。

## 4. 先确认协议，再接生产路径

Issue 提供的候选接口为：

`GET /rest/v2/searchSeats/{date}/{begin}/{end}?roomId={roomId}&page={page}`

这仍是提交者给出的线索，**不是本项目已经复现的接口契约**。实施方先用当前学校公开前端/既有脱敏资料和最小只读请求确认：部署是否支持、认证签名、分钟参数/特殊值、完整时段可约语义、名单字段、房间归属、业务错误、分页起点与结束规则。优先现有会话，不反复登录或尝试密码。

- 复用原 libseat 固定来源、签名、账号代次与清理门闩，不放开任意 URL、不记录 token/正文、不新增凭据持久化。
- 成功 HTTP 不等于业务成功。登录失效、学校拒绝、关闭、不合法时间、结构异常要分别处理。
- `layoutByDate` 状态不足以证明任意目标区间完整可约；也不根据接口名称臆断它一定只代表此刻。区间候选必须由验证过的区间接口提供，不能从地图 FREE 状态推导。
- 若实际接口不支持或语义与 Issue 不一致，保留真实证据并报告，不用本地推测名单替代、不把空结果当成功。隐藏功能与协议验证可独立推进。

## 5. 分页、筛选与数量

- 只查询当前房间，首次只读一页，后续点“加载更多”；每页大小以实际返回为准，不硬编码恒为 25。
- 正确跟随服务端 page/hasMore，座位按稳定 ID 去重；识别重复页、页号倒退或不推进，避免死循环。单次条件最多加载 20 页，达到上限显示“已加载前 N 个，请缩小范围”。不提供后台自动全馆爬取。
- hasMore=true 时写“已加载 N 个”，全部读完且无失败才可写“共 N 个”。可另显示“已隐藏 M 个”，这里的 M 只代表已加载候选中被个人隐藏的数，不伪装全馆数字。
- 下一页失败保留同查询条件下已读结果，显示“部分结果未加载”与重试；首屏失败不显示 0 个可约。条件变化立即清空旧条件结果，不把它们显示在新条件下。
- 后续分页必须校验完整查询键与账号/会话代次；切馆、换号、失效登录后不能合并旧候选。

## 6. 选择座位与最终确认

- 候选选择是单选；列表行显示座号，房间/日期/时段由上下文明确。可沿用现有确认对话框，明确位置、日期、开始、结束、时长。
- 候选中的“此刻已占用”不能单独否决其未来时段可约。现有 `canConfirmReservation()` 依赖布局 selectable，需拆分两种模式的有效性校验：原座位模式保留原守卫，时段模式依赖已验证的区间结果、静态允许条件和当前有效时间选项。
- 选定候选时调用该座位官方 startTimes/endTimes，匹配用户选择的实际 HH:mm；提交参数只能取学校返回的真实 id，不把显示字符串或自行算出的分钟冒充 id。不匹配时清除选择并提示“该座位时段已变化，请重新查找”。
- 若静态座位禁用/非真实座位/本地专用等条件真实提供，继续遵守；字段缺失不能在没有证据时擅自补默认值、又反过来拒绝整个候选名单。
- 确认入口与真正提交前都校验：当前模式/房间/日期/时段/选择未变、账号与会话上下文有效、相关请求结束且该候选和官方时间映射仍有效。网络读取迟到不得重新启用旧确认。
- 服务端提交仍是最终裁决，只发一次；被占用后拒绝要真实提示，不能自动换座或扩大时段。超时/结果未知先核对官方记录，不自动重提。验证码继续既有受限网页回退。

## 7. 个人隐藏座位

产品称“隐藏座位”，不称学校封禁或将个人偏好渲染成官方不可用。

- 候选行更多菜单：`隐藏此座位`。座位图中的真实座位长按可打开同一菜单（占用座位也可隐藏）；可用座位选中后的详情/摘要也提供该动作，避免只有长按入口。
- 隐藏后候选列表立即排除该项，若它正被选中则清空确认状态；用短 Snackbar 提示“已隐藏座位 006”，提供“撤销”。
- 地图保持真实坐标，不删除占位、不重排：个人隐藏位置弱化并用区分于占用状态的隐藏标记；图例中仅在存在隐藏项时补充“已隐藏”。默认不能直接预约隐藏项。
- 房间页更多菜单提供 `隐藏的座位（N）`，进入底部管理面板：当前房间隐藏项、逐项恢复、全部恢复。无隐藏时是简短空态。
- 仅本机保存，独立 DataStore/现有偏好层即可；key 至少包含 system=libseat、buildingId、roomId、稳定 seatId。可保存座号作为展示快照；学校更新编号时以当前官方布局名称优先。不同房间同编号不得串联。
- 这是设备本地座位偏好，不是学校账号数据，不上传、不影响他人；学校换号/退出不应无意删除它，恢复/清理入口明确。此次先限唐岛湾，结构保留来源键以免未来扩展串系统。
- 恢复只解除个人隐藏，不改变学校状态、不把占用座位变成可用。读写失败明确告知保存失败，不能假装已持久化。标题/偏好/座位详情不进诊断日志。

## 8. 页面状态与短文案

| 状态 | 展示/动作 |
| --- | --- |
| 未选完整时段 | 空列表下“选择时段，查找可约座位”；查询按钮禁用 |
| 查询中 | 控制区轻量进度，不遮挡整个页面；可取消 |
| 完整空结果 | “这个时段暂无可约座位”，提供修改时段 |
| 候选全被个人隐藏 | “可约座位已被隐藏”，提供查看/恢复隐藏项 |
| 初始失败 | “查询失败”与重试，不写暂无座位 |
| 下一页失败 | 保留当前条件结果，尾部“部分结果未加载”与重试 |
| 登录失效 | 沿用既有登录恢复，清空可提交选择 |
| 关闭/时间无效 | 仅在学校明确返回时使用对应短提示，不能由空数组推断 |

## 9. 验证与交付

先协议/业务后视觉，至少覆盖：分页/去重/上限/部分失败；完整区间跨占用；当前占用而目标未来可约；座位专用时间选项不匹配；过去/跨午夜等无效输入；官方日期与分钟 id；两种模式守卫不串；旧房间/账号/时段结果失效；个人隐藏跨重启/同编号隔离/选中隐藏/撤销/恢复；未知结果不重提。

只读实测范围为用户此前已授权的正常认证与最小必要学校读取，不执行真实预约、取消、签到。如确需使用已授权本机凭据，仅在本机过程内按既定格式读：第 1 行第一个冒号后的全部值是账号，第 2 行第一个冒号后的全部值是密码；标签不是账号，保留值内冒号/BOM/CRLF，不能输出任何值、长度、hash或片段，不修改原文件、不把凭据放CLI参数。不反复尝试密码。

测试 UI 使用合成数据，截图标清来源；学校实测只记录脱敏结构、分类与数目，不提交原响应/原图/学生记录。浅/深主题、1.0/1.5×、长房间名、小屏、空/分页失败/隐藏管理/底部确认、原座位流程和超星入口回归。
