# 2.0.4 · 超星两馆区预约交互与唐岛湾对齐

用户要求：古镇口东区（Chaoxing seat）、求是（Chaoxing seatengine）的预约功能与页面布局向已验收唐岛湾方案对齐。基线为已发布 2.0.3 / `bc3efaf`。本轮为本地候选，版本 2.0.4 / versionCode 25，不含发布授权。

## 页面与行为

沿用 [唐岛湾设计](2.0.3-library-time-search.md) 的页面结构、主题、间距和短文案，优先复用生产组件：返回/房间名称/馆区与日期 → 按座位选 / 按时段找 → 对应内容 → 固定底部选座与确认栏。二级页不显示主导航 dock。

- 默认按座位选，保留真实座位坐标图、原生确认提交与必要的官方网页回退；不再长期用“官方预约”取代原生主操作。
- 按时段找：开始/结束时间并列，显式“查找座位”，显示当前房间的区间候选，单选、座号、更多菜单、可选状态、空态/错误/重试与底部确认的样式和唐岛湾一致。日期/房间/时段/模式改变立即撤销旧选择和确认资格。
- 时段候选必须由已核实的超星区间占用协议支持。先查当前公开官方脚本与现有实现，分别核实 seat / seatengine 的参数、区间边界、禁用/非座位、日期/时刻单位、业务错误与完整性；不要照搬 libseat 的接口、分页或时间 ID。若官方接口确实按完整区间返回已用集合，可在完整真实座位集合中排除；若数据只表示当前状态或语义未确认，不能冒充整段候选，必须如实反馈缺口。
- 只查当前房间，不循环逐座扫全馆。未返回分页就不虚构分页；有分页则严格跟随服务端，完整后才写总数。查询失败、缺字段、状态未知不得表现为全部可约。
- 最终确认列明馆区/房间/座号/日期/起止/时长，提交前重新核对当前查询、账号、会话、时间规则与座位状态。保留超星真实 submit 参数和校验字段，不套用唐岛湾时间 ID。

## 个人隐藏

补齐与唐岛湾同样的隐藏入口、立即清选、撤销、地图弱化标记、当前房间管理/逐项及全部恢复。优先扩展现有 `LibraryHiddenSeatsStore`，保持原 libseat 键及已保存数据兼容。

隐藏键必须区分 `libseat / chaoxing-seat / chaoxing-seatengine`、馆区或租户、房间与稳定座位身份；不能因两套超星同房间 ID/座号而互相隐藏。只在本机保存，换学校账号/退出不会误删；恢复不改变学校占用状态。存储为原子读改写，损坏/读写失败真实提示，迟到响应不能污染新房间。

## 并发与提交

所有异步读取、隐藏操作、最终预检和提交响应绑定房间/模式/日期/起止、查询代次、账号与会话代次。账号变化后不能混用新旧 Cookie 或复活旧选择。隐藏选中项立即失效确认，迟到数据不能恢复。

保留现有 Unknown 防重；同会话中关闭/重进详情页、重建 ViewModel 后，同一未知请求不可再次 POST。POST 前的验证码/预检失败不标成已发送；验证码/风控才转受限官方页。防重若仅进程/会话内有效必须如实记录，不能宣称重启后仍有保障。

## 实施取证与技术选择（2026-11-08）

本节记录本地候选的最终实现，不修改 2.0.3 的历史验收口径。

- 已通过学校正常 CAS 自动认证、本人核验和两套区域列表最小只读；未执行预约、取消、签到。
- 本轮从当前官方页面定位并读取公开脚本：
  [seat](https://office-static.chaoxing.com/r/staticreserve/js/src/front/apps/seat/submit/third/seat_select_third.js)、
  [seatengine](https://office-static.chaoxing.com/r/staticreserve/js/src/front/apps/seatengine/submit/third/seat_select_third.js)。
  两者 `confirmTime(type=1)` 在完整起止和时长规则检查后，调用各自 `getusedseatnums`，
  将 `data.seatReserves` 中的座号标成不可选，其余保留可选。这支撑「学校完整区间候选」语义，
  不是从当前地图颜色推导未来。seat 带 `fidEnc`，seatengine 带 `seatId`；两者均为 HH:mm 字符串，日期 YYYY-MM-DD。
- 官方脚本对 `seatAttributes.isReserve=0` 禁用座位；新增严格解析该属性并排除。
  `success` 缺失、占用项缺座号、无属性数组、重复/损坏/不完整坐标、容量不匹配不产生可约候选。
  没有自行补分页、设施排名、查询上限或使用 libseat 时间 ID。
- 官方页面的选择导航带 `deptIdEnc` 与 `fidEnc`；预检读取补齐这组固定租户上下文。
  `submit_enc` / `enc` 与 seatengine `wfwEngineEnc` 的真实提交规则保持分离；仅明确确认后一次 POST。
- 所有请求以无凭据的账号/代次/会话上下文、房间、日期、模式、起止和请求代次隔离。
  预检重新读取房间规则与区间占用；真正发送前再次校验上下文和选择。切换、隐藏或换号后迟到响应不能复活确认。
- 隐藏偏好沿用原 DataStore 原子 edit，旧 libseat 方法保留，超星使用显式来源 + 固定租户/馆区 + 房间 + 官方 seatNum。
  三套来源互不恢复/删除；读写失败不显示保存成功。隐藏立即清选，撤销只恢复偏好、不恢复旧选择。
- 复用唐岛湾 `TimeRangeControls`、候选行、隐藏管理面板和底部摘要；超星详情以回调组件供真实页面和 debug 合成验收共同调用。
  字体 1.5× / 窄屏底栏上下排列，长标题顶栏自然增长；不迁移 Compose、导航、AGP 或 RemoteViews。
- Unknown 防重仅存在 AppGraph 中的 Service 内存，跨详情关闭/新 ViewModel 有效；**进程重启或重新建立会话不保证保留**。
  只有真正 POST 边界登记，预检失败/验证码不登记已发送。学校端并发占用与真实提交结果仍由服务端裁决。
- 公共脚本证明官方采用所选完整区间的占用集合；没有对所有座位、所有重叠端点和所有日期做真实穷举。
  半开区间重叠等边界用合成服务回归验证客户端参数与候选派生，不能冒称已验证学校后端的逐分钟端点行为。

构建、截图、签名、产物与未覆盖范围见 [本地候选验收](../releases/2.0.4-chaoxing-library-parity.md)。

最终会话守卫另将 Cookie 显式绑定到已核验的账号/代次/会话上下文。新账号门闩不能重新认领旧 Cookie；迟到旧读取的失效清理也必须匹配原会话代次，不能因 Cookie 文本相同而清掉新会话。验证码/风控按钮使用现有受限 WebView 路由。


### 评审增量：响应不确定性与合法时段

POST 包络采用严格类型解析，未知/缺字段不等同拒绝；POST 后异常均为 Unknown，取消保持取消且保留键，VM 以实际发送边界区分“未提交”。只有布尔 false + 合法非空文本业务消息的明确拒绝允许释放本次键。
时段默认、选择器、查询和预检使用同一纯派生规则，Clock 可注入。开始必须位于学校网格且未过去，并存在符合 min/max 的真实结束；换开始保留合法旧结束或取最早合法结束，无时段显示短空态。最终占用预检也拒绝房间集合外座号。本轮不重新认证或执行真实接口请求。
