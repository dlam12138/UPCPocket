## 实施范围

### 日程待办与排序

- 课表和专注共用日程待办。勾选后的任务保留在原行，标题加删除线，点同一选框可取消完成。各行按任务 ID 独立保存。提交中的选框暂时禁用，写入失败时恢复可操作并提示。折叠时显示前四项，可展开查看其余事项。未完成数单独显示。「全部待办」按完成状态分组。 [日程筛选](../../feature/todo/src/main/kotlin/com/upcpocket/app/ui/todo/TodoSchedule.kt) · [日程卡片](../../feature/todo/src/main/kotlin/com/upcpocket/app/ui/todo/TodoScheduleSection.kt) · [宿主导航](../../app/src/main/java/com/upcpocket/app/ui/nav/AppNav.kt)
- 有截止或提醒的任务显示在对应日期，同一天只出现一次。因逾期或无日期出现在「今天」的任务，完成后按设备本地完成日期保留。逾期项在完成日仍按原截止时间排序。次日只继续带入未完成的逾期和无日期任务。切换宿主或重开应用时从同一 Room 数据恢复。
- 在「全部待办」选择日期、重要程度或手动排序。默认按日期。未完成项先按截止时间升序列出有截止的任务，再按创建时间倒序列出无截止的任务。已完成项按完成时间倒序。日程待办先按选中日筛选，再使用所选模式，日期模式按该日命中的截止和提醒时刻排序。
- 编辑待办可设高、普通、低三个重要程度，旧任务和新建表单默认普通。同级沿用各自视图的日期顺序。
- 手动模式在完整列表的未完成和已完成分组内提供「上移」「下移」。手动顺序按任务 ID 保存，切换模式再返回时恢复。初始化后新增任务排在末尾，已有位次的任务在撤销删除时恢复原位。重排在一次事务内更新排序记录，保留任务的截止、提醒时间、已发送状态和 `revision`。 [待办排序](../../feature/todo/src/main/kotlin/com/upcpocket/app/todo/data/TodoOrdering.kt)
- 完成和取消完成继续用任务 ID 加当前 `revision` 执行条件写入，并沿用提醒协调。桌面待办继续读取未完成摘要，原有通知与新增入口继续指向现有路由。 [TodoStore 与系统消费者](../../API.md#业务能力与系统消费者)

### 个人日程与今日安排

- 课表日期入口与日程待办的新增入口共用本机编辑流程，可选择创建「待办」或「日程」。日程填写标题、开始日期和时刻、结束日期和时刻，以及可选地点或备注。结束必须晚于开始。例子为某日 14:00–16:00 的讲座或考试。使用个人日程承载时间段，待办继续独立设置截止和一次性提醒。
- 课表对应日期显示个人日程标记和按时刻查看的列表，任意时段和重叠日程都可查看。日程待办按所选日期显示本机日程。首页「今日安排」，汇合课程和个人日程并清楚标记来源。课表加载、未同步或插件缺失时，仍可在首页查看本机日程。仅课表能力可用时，沿用课程展示与同步入口。日程待办移至专注页后，可继续从课表和首页查看个人日程。 [现有首页](../../app/src/main/java/com/upcpocket/app/ui/home/HomeScreen.kt) · [课表插件入口](../../feature/timetable/src/main/kotlin/com/upcpocket/app/timetable/TimetablePlugin.kt)

### 首页纪念日正计时与倒计时

### BUG-211-01：今明课表组件单日最多仅显示 3 节课

- **复现与表现**：在桌面添加「今明课表」组件后，默认高度下一天只展示 2 节课；即使将组件纵向拉到最大高度，单日也只显示 3 节课，其余课程被折叠进右上角 `+N`。
- **源码定位**：
  - [TimetableTodayTomorrowWidgetSnapshot.kt](../../feature/timetable/src/main/kotlin/com/upcpocket/app/timetable/TimetableTodayTomorrowWidgetSnapshot.kt) 中 `TimetableTodayTomorrowWidgetLayout.forSize()` 按高度和字号将 `maxCoursesPerDay` 分档为 `1 / 2 / 3`（`height >= 180 && fontScale < 1.15f` 时封顶 3），并硬编码常量 `MAX_TODAY_TOMORROW_COURSE_LINES = 3`。
  - [widget_timetable_today_tomorrow.xml](../../feature/timetable/src/main/res/layout/widget_timetable_today_tomorrow.xml) 与 [TimetableTodayTomorrowWidgetRenderer.kt](../../feature/timetable/src/main/kotlin/com/upcpocket/app/timetable/TimetableTodayTomorrowWidgetRenderer.kt) 每列只预置了 3 个课程 `TextView` 槽位（`course_1`–`course_3`），纵向拉伸后无法继续增加可见课程行数。
  - [WidgetUpdates.kt](../../app/src/main/java/com/upcpocket/app/widget/WidgetUpdates.kt) 原先对今明组件沿用保守最小高度，导致竖屏纵向拉高时未能拿到真实竖屏高度。
- **修复与验证**：
  - 将每列课程槽位扩展到 **8** 行（`MAX_TODAY_TOMORROW_COURSE_LINES = 8`，`course_1`–`course_8`，默认隐藏且 `reapply` 全量清理），`TimetableTodayTomorrowWidgetLayout.forSize()` 改为按可用高度、日期行、有效字号与安全余量动态计算行数（默认 `250×140@1.0x` 显示 5 节，纵向拉伸最高 8 节，超出由 `+N` 展示；窄卡大字号 `180×110@1.5x` 保持无裁切）。
  - [WidgetUpdates.kt](../../app/src/main/java/com/upcpocket/app/widget/WidgetUpdates.kt) 为今明组件启用 Android 12+ 响应式 `RemoteViews(Map<SizeF, RemoteViews>)`：优先读取 `OPTION_APPWIDGET_SIZES`（含 `runCatching` 保护、API 33 类型安全读取与 16 项上限），单尺寸时补入有效旧上下界候选，缺少 `minHeight` 且现有候选全高于 140dp 时追加 140dp 保守安全候选，避免部分 Launcher 旋转不回调 options 时裁切底部课程；本周课表仍沿用原有保守尺寸路径。
  - 定向单测通过：`feature:timetable` 18/18（`TimetableTodayTomorrowWidgetTest` 8、`TimetableTodayTomorrowWidgetRendererTest` 10）、`app` 26/26（`WidgetSizeTest` 12、`WidgetIntentsTest` 14）、`checkModuleBoundaries` 与 `:app:assembleDebug` 均通过，独立审查通过。真机 Launcher 实际拉伸、横竖屏旋转及不同系统字体待设备验收。

### BUG-211-02：轻量玻璃主题下日期选择器年份列表与日历网格重叠

  - Material 3 原生 `DatePicker` 展开年份选择器时，在月历网格上方叠加一层使用 `colors.containerColor` 填充的 `Surface`；当该颜色被设为完全透明时，年份浮层失去遮挡，导致底层月历透出并与年份文字重叠。
- **修复与验证**：
