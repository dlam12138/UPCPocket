## 调研依据

- WakeUp 的 Android 文档列出今日、近日、一周和日视图四类组件，其中部分可自定义样式。今明并排是一张用户示意图表达的需求，具体版式使用本项目的组件风格。 [WakeUp 桌面小部件](https://www.wakeup.fun/doc/widget.html)
- Android 12（API 31）起支持按网格指定组件初始尺寸和按实际空间提供响应式 RemoteViews。桌面和网格会影响可用 dp。系统的 `updatePeriodMillis` 周期下限为 30 分钟，事件和本地任务也可以触发更新。今明版适合复用现有本地重绘链路，午夜更新时间以桌面和系统调度为准。 [Android 组件布局](https://developer.android.com/develop/ui/views/appwidgets/layouts) · [组件更新方式](https://developer.android.com/develop/ui/views/appwidgets/advanced)
- Google Tasks 的 Android 版提供按截止日期、最近加星及手动顺序等排序方式。Google 日历将计划开始与结束时间和任务截止日期分别设置。UPC Pocket 的待办排序和日程时段可各自处理，按同一天汇合展示。 [Google Tasks 排序](https://support.google.com/tasks/answer/7675629?co=GENIE.Platform%3DAndroid&hl=en) · [Google 日历任务时间](https://support.google.com/tasks/answer/9901136?hl=en)
- Room 支持增量迁移和迁移测试。2.1.0 正式版的 `upcpocket-todo.db` 为 v2，已有 v1 → v2 的可空截止字段迁移。2.1.1 开发版 v2 → v3 新增排序记录，v3 → v4 新增个人日程表。两步迁移保留原任务表和 v1 升级路径。 [Room 迁移](https://developer.android.com/training/data-storage/room/migrating-db-versions) · [TodoDatabase](../../feature/todo/src/main/kotlin/com/upcpocket/app/todo/data/TodoDatabase.kt) · [数据归属与兼容](../../ARCHITECTURE.md#数据所有权与兼容) · [ADR 003](../adr/003-data-ownership-and-schema-compatibility.md)
- 用户提供的成绩页和现有课表页同属 `app.upc.edu.cn`。2026-11-23 匿名请求成绩入口收到 HTTP 200，成绩业务的认证方式、本人核验、字段、学期覆盖及分页仍待确认。 [学校成绩页](https://app.upc.edu.cn/site/score/index) · [现有课表来源](../upc/官方入口.md#课表来源与验证边界)
- 教务处成绩证明指南给出必修课五分制平均学分绩点的学分加权口径，适用范围是该证明模板。教务处当期学业警示通知另按培养计划相关学分核对，并提示学分冲抵可影响结果。移动成绩页的总 GPA 和学分字段含义需以实际教务来源核实。 [教务处成绩证明指南](https://jwc.upc.edu.cn/_t34/2013/0929/c22241a372563/page.psp) · [2026–2027 学年第一学期学业警示通知](https://jwc.upc.edu.cn/2026/0910/c18519a499499/page.htm)

## 实施范围

### 日程待办与排序

- 课表和专注共用日程待办。勾选后的任务保留在原行，标题加删除线，点同一选框可取消完成。各行按任务 ID 独立保存。提交中的选框暂时禁用，写入失败时恢复可操作并提示。折叠时显示前四项，可展开查看其余事项。未完成数单独显示。「全部待办」按完成状态分组。 [日程筛选](../../feature/todo/src/main/kotlin/com/upcpocket/app/ui/todo/TodoSchedule.kt) · [日程卡片](../../feature/todo/src/main/kotlin/com/upcpocket/app/ui/todo/TodoScheduleSection.kt) · [宿主导航](../../app/src/main/java/com/upcpocket/app/ui/nav/AppNav.kt)
- 有截止或提醒的任务显示在对应日期，同一天只出现一次。因逾期或无日期出现在「今天」的任务，完成后按设备本地完成日期保留。逾期项在完成日仍按原截止时间排序。次日只继续带入未完成的逾期和无日期任务。切换宿主或重开应用时从同一 Room 数据恢复。
- 在「全部待办」选择日期、重要程度或手动排序。默认按日期。未完成项先按截止时间升序列出有截止的任务，再按创建时间倒序列出无截止的任务。已完成项按完成时间倒序。日程待办先按选中日筛选，再使用所选模式，日期模式按该日命中的截止和提醒时刻排序。
- 编辑待办可设高、普通、低三个重要程度，旧任务和新建表单默认普通。同级沿用各自视图的日期顺序。
- 手动模式在完整列表的未完成和已完成分组内提供「上移」「下移」。手动顺序按任务 ID 保存，切换模式再返回时恢复。初始化后新增任务排在末尾，已有位次的任务在撤销删除时恢复原位。重排在一次事务内更新排序记录，保留任务的截止、提醒时间、已发送状态和 `revision`。 [待办排序](../../feature/todo/src/main/kotlin/com/upcpocket/app/todo/data/TodoOrdering.kt)
- 完成和取消完成继续用任务 ID 加当前 `revision` 执行条件写入，并沿用提醒协调。桌面待办继续读取未完成摘要，原有通知与新增入口继续指向现有路由。 [TodoStore 与系统消费者](../../API.md#业务能力与系统消费者)

### 今明课表组件

- 可在系统小组件列表和「设置 → 桌面组件」添加独立「今明课表」。默认约 4×2，两日各列日期、节次和课程名，超出行数分别显示数量。根据 Launcher 实际宽高和字号精简文字，保留两日及各自的状态。整卡打开「课表」。课表插件缺失时显示「课表功能不可用」，点击回首页。 [组件入口](../m5/README.md#210-后开发改动2026-11-24未发布) · [课表组件视觉](../m5/2026-11-05-组件视觉修订.md)
- 以 `Asia/Shanghai` 的实际今天和次日读取当前账号已成功缓存的两天。周六的明天可能属于另一个教学周，按两日真实日期查找覆盖。两栏分别显示有课、已同步无课、该日未同步或学期外等结果，读取失败保留对应说明。复用本地缓存读取和发布前的账号、代次、日期复核。
- 同步成功、组件尺寸变化、时间变化和上海跨日触发本地重绘。今明、今日和本周版共用一次性边界任务及 30 分钟周期兜底。已放置今日版时安排课时和分钟边界，只放今明或本周时安排上海午夜。系统后台限制可能推迟自动更新。 [周快照](../../feature/timetable/src/main/kotlin/com/upcpocket/app/timetable/TimetableWeekWidgetSnapshot.kt) · [课表服务](../../feature/timetable/src/main/kotlin/com/upcpocket/app/timetable/TimetableService.kt) · [宿主组件调度](../../app/src/main/java/com/upcpocket/app/widget/TimetableWidgetTicker.kt)

### 个人日程与今日安排

- 课表日期入口与日程待办的新增入口共用本机编辑流程，可选择创建「待办」或「日程」。日程填写标题、开始日期和时刻、结束日期和时刻，以及可选地点或备注。结束必须晚于开始。例子为某日 14:00–16:00 的讲座或考试。使用个人日程承载时间段，待办继续独立设置截止和一次性提醒。
- 课表对应日期显示个人日程标记和按时刻查看的列表，任意时段和重叠日程都可查看。日程待办按所选日期显示本机日程。首页「今日安排」，汇合课程和个人日程并清楚标记来源。课表加载、未同步或插件缺失时，仍可在首页查看本机日程。仅课表能力可用时，沿用课程展示与同步入口。日程待办移至专注页后，可继续从课表和首页查看个人日程。 [现有首页](../../app/src/main/java/com/upcpocket/app/ui/home/HomeScreen.kt) · [课表插件入口](../../feature/timetable/src/main/kotlin/com/upcpocket/app/timetable/TimetablePlugin.kt)
- 所有个人日程入口统一按 `Asia/Shanghai` 录入和编辑，表单标注「上海时间」，起止保存为确定时点。设备更改时区后重开表单，仍显示和保存原上海时间。选择的时刻无法唯一对应实际时间时，例如时区规则造成当地时间跳过或重复，提示改选。课表及首页「今日安排」沿用上海日期，日程待办沿用设备本地日期。跨日取时间段与日期的交集，零点结束的日程计至前一日。设备时区与上海不同时，显示时段的视图注明时间口径。
- `feature:todo` 持有个人日程独立表与读写入口，Room v3 → v4 追加日程表和时间索引。宿主从最终激活能力接入，按窄契约注入课表和首页所需展示数据、编辑入口，feature 之间保持独立。学校课表继续按账号保有只读缓存，换号或删号时撤下旧课程并拒绝迟到快照，保留个人日程、待办和本机偏好。 [模块边界](../../ARCHITECTURE.md#模块与依赖) · [隐私与数据](../PRIVACY.md)

### 首页纪念日正计时与倒计时

- 在「设置 → 应用 → 首页纪念日」填写标题、日期，选择正计时或倒计时。开启后在首页日期下方显示一行，默认关闭，关闭时保留已保存的纪念日。
- 正计时在起始日前显示「还有 N 天开始」，起始日为第 1 天。倒计时在未来显示「还有 N 天」，目标日显示「就是今天」，过期显示「已过 N 天」。与首页共用上海日期，进入首页、应用回到前台和跨日时按当前日期重算。设置仅保存在本机。重复规则留待后续评估。 [首页日期与页头](../../app/src/main/java/com/upcpocket/app/ui/home/HomeScreen.kt)

## 开发次序与验收

日程待办原位勾选、排序、今明课表、个人日程和首页纪念日已实现。备忘录预研先验证独立无日期条目能保存、重开和编辑。只看课表先试用「日程待办位置 → 专注」和桌面组件直达，再评估「仅看课程」视图对同步、返回、现有组件和入口回退的影响。独立安装包或全局切换留待专项评估。

成绩与学分可并行准备页面。确认学校授权范围、本人会话和学期查询协议后，再接入原生只读同步。先验收明细，逐项核对后启用总览指标。若原生来源尚未核实、学校网页已验证可查询，候选版可先提供固定网页入口。

卓越楼平面图先逐页核对楼层和房号，再录入原生绘图数据并注册独立服务入口。可先交付已核对的楼层与查找结果。

| 后续验收 | 最小检查 |
| --- | --- |
| 卡片拖动与外观 | 在真机开启开关后分别调整首页和课表顺序，关闭后重开应用，核对顺序仍锁定。通过系统照片选择器选图和换图，核对取色、重开后的背景和恢复默认。 |
| 待办原位勾选 | 在课表和专注位置各连续勾选两项，重开后检查同日行位置和完成状态，再分别取消完成。 |
| 待办排序 | 在「全部待办」切换三种排序，核对课表和专注的日程待办同步显示。重开后检查所选模式，切回手动核对自定义次序。删除一项、另建一项再撤销删除，检查原项的位置和新项在末尾。在允许提醒的设备上移动一项待触发的任务，核对截止和提醒时刻，并验证提醒触发一次。 |
| 今明组件 | 同时看到有课和已同步空日，周六／周日邻接一日未同步时明确提示。检查宽卡和缩小后的文字、整卡导航、午夜及账号切换后的快照归属。 |
| 个人日程与升级 | 添加、修改和删除讲座或考试，在周课表、日程待办和首页核对同一条。一条跨午夜日程按日期正常呈现。将设备设为东京时区，用上海时间 23:30–23:50 的日程核对课表与首页归当日、日程待办归次日，重开表单核对原上海时段。从 2.1.0 保留数据覆盖安装，核对旧任务 ID、完成状态、截止、提醒及 `revision`，验证原 v1 迁移链可继续升级。 |
| 纪念日 | 核对起始日、目标日前与目标日/过期的文案，关闭后首页回到原布局，换号后仍可看到已保存设置。 |
| 成绩与学分 | 用已授权的本人真实账号走正常学校认证，读取并对照一个学期的课程成绩、学分和已启用的统计。用合成数据核对筛选、缺项、完整空结果和已启用的本地计算规则。检查断网后仍能查看本账号快照，换号或删号后旧成绩即时撤下、迟到结果无法写回。 |
| 卓越楼平面图 | 核对服务入口与搜索结果均指向楼层图独立页面。断网、未授权定位时从服务页打开 A、B，检查切楼层、缩放和房号查找。逐层对照原图，以 A233 和 B328 核对图注二层和一层，再核对现场楼层标识。检查 B2xx 待确认和未知房号的提示。核查候选 APK 的卓越楼资源清单，确认仅含重绘数据和必要元数据，原 PDF 和整页转图均留在核对资料中。 |
