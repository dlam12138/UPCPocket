# 2.0.8 · 官方校历查看调研与计划

日期：2026-11-17。状态：**已纳入 2.0.8 更新计划，未实施、未构建、未设备验收**。当前正式版仍为 2.0.7 / 28。依用户后续将#8/#9合入纳入版本的要求，入口按服务目录与首页固定机制对齐，优先级P1；详见 [总计划](2.0.8-update-plan.md)和 [CHANGELOG](../CHANGELOG.md)。

## 官方来源与证据

| 来源 | 本轮核实结果 |
| --- | --- |
| [教务处「校历」栏目](https://jwc.upc.edu.cn/603/list.htm) | 中国石油大学（华东）教务处、荟萃学院官网的公开栏目；HTTPS 可读，无需 CAS，按学年列出文章 |
| [2026–2027 学年校历](https://jwc.upc.edu.cn/2026/0508/c603a490075/page.htm) | 查阅时栏目最新文章，发布于 2026-05-08；正文为两张 JPG 校历图，分别对应两学期 |

公开校历图包含本科生、研究生分别报到/开课及全校学生等安排说明，未按唐岛湾与古镇口分列；据此不推断每个培养类型、校区或个人课程安排均相同。学校门户另有「学校日历」入口，不将它与教务处的学年校历混用。

HTML 与两张图片已完成公开只读核对，没有使用学校账号。页面声明可缩放 viewport，图片信息密集，**真实手机的图片加载、缩放和横屏阅读尚未验收**。HTTPS 可用，不依赖 HTTP 自动跳转，也不降低证书校验要求。

## 建议接入方式

**首版采用「服务 → 学习与空间 → 校历 → 系统浏览器打开官方校历栏目」**，支持通过#8的图钉机制固定到首页，同时在已有「校园网页 → 学习」区域加入同一目标。链接固定为 `https://jwc.upc.edu.cn/603/list.htm`，由同学选择所需学年。不额外维护一套首页快捷清单；不擅自将校历加入#8的四个默认固定项。

栏目能持续列出新旧学年，适合作为默认入口；年度文章和图片只作为来源证据，首版不固定某一学年或直接绑定图片地址。学校可能提前发布下一学年校历，不能将列表第一篇自动称为“当前学年”。栏目结构或地址发生变化时仍需维护，不能承诺永久免更新。

| 方案 | 优点与代价 | 本计划选择 |
| --- | --- | --- |
| 系统浏览器打开官方栏目 | 复用现有外链方式；保留官方完整内容与学年列表，维护范围小；需要联网，阅读体验由学校页面和浏览器决定 | **首版推荐** |
| 应用内 WebView | 阅读留在应用内；需新增公开网页容器并处理返回、跳转、图片和安全边界，现有业务认证 WebView 不宜直接借用 | 暂不纳入首版实现 |
| 原生图片查看或解析日期 | 可定制缩放、学年选择和离线体验；需维护栏目/文章/图片发现、缓存时效和大图加载，图片日期不能直接当结构化教学数据 | 后续有明确需求再评估 |

当前需求是查看官方校历。首版不新增离线校历、日历订阅、系统日历写入、节假日提醒或校历解析服务。

## 与现有项目的衔接

- [HomeScreen](../../app/src/main/java/com/upcpocket/app/ui/home/HomeScreen.kt) 当前main在插件服务旁添加宿主「校园网页」快捷卡；2.0.8按#8的新服务目录提供宿主「校历」条目并支持首页固定，复用统一图钉状态，不在旧首页另追加一份固定清单。#8已有五Tab候选，不为校历再增加一个Tab。
- [OfficialWebScreen](../../app/src/main/java/com/upcpocket/app/ui/official/OfficialWebScreen.kt) 当前维护固定学校链接，以新建的 `ACTION_VIEW` + `CATEGORY_BROWSABLE` Intent 交浏览器，并处理没有浏览器与系统拒绝的情况。校历复用这套行为，首页和目录共用固定 URL 与打开逻辑，避免两处链接逐年分叉。
- [AppNav](../../app/src/main/java/com/upcpocket/app/ui/nav/AppNav.kt) 现有宿主「校园官方网页」路由保留。服务条目和首页固定条目共用宿主外链动作；#8现有条目点击主要按插件route处理，实施时补齐宿主固定外链的接线，不依赖课表插件，也不为外链引入独立feature或数据库。不将学校URL、浏览器Intent或AppGraph塞进课表领域模型。
- 校历是公开宿主入口，不依赖课表插件、已保存账号或学校会话；课表插件不可用时也能查看官方校历。页面预加载和首页显示不自动发请求，仅用户点按后打开浏览器。
- 新建外链 Intent 只使用应用固定的 HTTPS 地址，不透传外来 URL、嵌套 Intent、账号或会话，不预填登录；浏览器原有的状态由浏览器管理。现有认证 WebView 的 Cookie、凭据边界保持。
- 应用只确认浏览器是否启动，不将启动成功表述为网页已加载或校历已更新。无浏览器或系统禁止时显示已有的短错误；离线、学校维护或图片加载失败由浏览器真实表达，不补造日期或声称已离线缓存。

## 数据与维护边界

校历只供查看，**不替换课表服务确认的真实学期、当前教学周或课程结果**。不得从图中开学日期推算本人周次、自动修改缓存，或将临时调休与个人补课等同。

来源登记于 [官方入口](../upc/官方入口.md)和[入口 JSON](../upc/official-entrypoints.json)，标明“计划、未实施”；JSON 继续是开发资料，不作为运行时远程配置。实施时同步 README 的使用入口、M5 入口映射和相关隐私说明；若实际引入内部契约，再同步 ARCHITECTURE/API。历史发布记录保持原文。

后续实施只需按实际影响核对：服务目录、首页固定与官方网页目录打开同一正确的官方HTTPS栏目；未保存账号或课表插件不可用时仍可进入；固定/取消后与首页一致；浏览器返回保留页面和搜索/滚动状态；手机能选择学年、加载两学期图片并阅读缩放；没有可用浏览器时不崩溃。遵守总计划的页面稳定性要求，仅做必要系统跳转与阅读冒烟，不进行学校登录或无关设备矩阵测试。
