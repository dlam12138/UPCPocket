# UPC Pocket 共创提案 · 校园地图导航

想给 UPC Pocket 加个校园地图，方便大家找楼、走路和骑车。

- 唐岛湾、古镇口都做，各自支持校内导航。服务页可以打开，也能固定到首页。
- 地图能定位，可以点选目的地、搜楼名和简称，也能从课表地点直接进入。首批覆盖教学楼、宿舍、食堂和图书馆。
- 步行、骑行各最多 3 条路线，显示预计时间和距离，默认最快。在 App 内边走边看地图和文字指引，走偏自动重算。

先用百度地图做个小样，高德作对照。重点验证校内小路、楼门入口，以及能不能沿选中的路线走。封门、施工和禁骑等路况后续一起补。

欢迎发一条你常走的「校区＋起点 → 终点」，楼名简称和常用入口也可以一起说。
