# 2.0.9 更新待开发

## 评估是否值得重构前端

**待评估。** 以 2.0.8 回滚前的 Kyant 液态玻璃为视觉基线，目标是实现 iOS Liquid Glass 的通透感和触摸反馈。2.0.8 的实时玻璃候选曾在手机上出现卡顿。 [2.0.8 开发记录](../releases/2.0.8-development.md#2026-11-18-应用主题与桌面外观决定) · [ADR 006](../adr/006-2.0.8-material-theme-and-glass-widgets.md) · [Apple 材质设计](https://developer.apple.com/videos/play/wwdc2025/219/)

- 先在现有 Compose / Material 3 主题中用 Kyant 材质做底栏样例。滚动正文经过底栏时保留实时折射，选中胶囊按压和拖动时保留高光与跟手形变，并检查深浅色文字和图标对比度。 [旧候选依赖记录](../research/2026-11-17-2.0.8-dependency-provenance.md)
- 参考社区项目的 Material 3 玻璃效果。其 1.0.0 Android 制品最低 `compileSdk` 为 37，当前工程为 36。 [社区 Material 3 适配](https://github.com/shayann07/liquidglass/blob/v1.0.0/docs/material3.md) · [Maven Android 制品](https://repo.maven.apache.org/maven2/dev/shayxo/liquidglass/liquidglass-material3-android/1.0.0/liquidglass-material3-android-1.0.0.aar)
- 在上述视觉条件下评估局部采样、背景复用和合并滤镜。 [Haze 实测](https://chrisbanes.github.io/haze/2.1.0/benchmark-results/) · [Kyant 滤镜合并对照](https://github.com/Kyant0/AndroidLiquidGlass/issues/126)
- 以 Material 3 的流畅度为基线，在同一台 Android 真机用 Release 构建对照滚动和切换 Tab。比较不同玻璃实现时使用相同效果和刷新率，记录 P95 帧超时量和超时帧比例。
- 其他 Android 方案可参考 Go/Gio 与 Flutter。 [Gio Android 构建](https://gioui.org/doc/install/android) · [Flutter 在 Pixel 7 上的效果](https://github.com/shayann07/liquidglass/blob/main/review/atlas/flutter-2026-10-19/README.md#pixel-7-vulkan--20-october)
- 综合视觉效果、真机性能、Android 兼容性和迁移维护成本，给出是否值得重构以及建议范围。

## 常用校区与服务分组

**待开发。** 在现有「设置 → 校园」中加入「常用校区」，可选择唐岛湾、古镇口或全部校区。已有有效选择时按保存值恢复，缺少有效偏好时默认「全部校区」。设定常用校区后，功能页默认展示该校区。页内临时切换只在当前访问生效，重新进入时恢复常用校区。 [Issue #10](https://github.com/dlam12138/UPCPocket/issues/10) · [已回复](https://github.com/dlam12138/UPCPocket/issues/10#issuecomment-6967899317) · [设置入口](../../app/src/main/java/com/upcpocket/app/ui/settings/SettingsScreen.kt)

常用校区可写入现有本机 `UiPrefsStore`，由宿主向对应页面传入默认值。复用既有路由和学校查询。校园卡、个人课表、校历和本机工具属于通用服务。 [偏好存储](../../app/src/main/java/com/upcpocket/app/data/prefs/UiPrefsStore.kt) · [宿主与插件边界](../../ARCHITECTURE.md#启动扩展与导航)

| --- | --- |
