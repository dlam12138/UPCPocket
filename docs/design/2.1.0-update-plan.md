## 校园地图与前台导航

地图、公开地点和路网随应用提供，在本机搜索与算路。手动起点用于预览；开始导航采用最新可信定位，随行进更新剩余路线，确认偏航后从新位置重新规划。唐岛湾楼内起步仅使用可明确匹配楼栋的已标注楼外入口及现有道路接入点。

古镇口东区可在已有连通道路上选路，西区目前以地点浏览为主。现场通行与手机定位仍待验收。地图数据来源、当前范围和历史验证见 [ADR 007](../adr/007-offline-campus-navigation.md)与[导航开发记录](2026-11-19-campus-navigation-implementation.md#6-2026-11-20-现有覆盖验收)，位置处理见[隐私说明](../PRIVACY.md#校园地图与前台定位)。
