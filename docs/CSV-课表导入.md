# 本地 CSV 课表导入与登录后导出

课表右上角“导入” → 选择 CSV 文件，或“从剪贴板导入” → 核对当前学期和预览 → 确认。系统文件选择器可选本机或用户自选的文件提供方；App 只读取所选文件，不保留 URI 权限、不上传。写入在同一 Room 事务内完成，任一写入失败整批回滚。导入后刷新课表和桌面组件，演示数据不写入数据库。

模板：[课表导入模板.csv](课表导入模板.csv)。示例数据虚构。支持 UTF-8（含 BOM）及 GB18030，标准 CSV 引号、逗号、引号内换行；文件至多 2 MiB、2000 条时段。不能把 Excel .xlsx 直接改后缀，需另存为 CSV。

## 支持的表头

必填：

- 课程名称：`课程名称` / `课程名` / `课程` / `科目` / `教学班` / `教学班名称`
- 星期：`星期` / `星期几` / `周几` / `上课星期` / `上课日`；值为 1–7 或星期一至星期日
- 周次：`周次` / `上课周次` / `教学周` / `周数` / `起止周`
- 节次二选一：
  - `开始节次`（`起始节次` / `起始节` / `开始节` / `起始节数` / `起节`）+ `结束节次`（`终止节次` / `结束节` / `结束节数` / `止节`）
  - 或单列 `节次` / `上课节次` / `课节` / `节数`
  - 或单列 `上课时间` / `排课时间` / `时间`（保守格式，见下）

可选：教师（`教师` / `任课教师` / `教师姓名` / `授课教师` / `老师`）、教室（`教室` / `上课地点` / `地点` / `教学地点` / `教室名称`）、单双周（`单双周` / `周类型` / `单双`）。未知列忽略；缺关键列、歧义重复列或任何错误记录禁止整批确认，不猜测。

## 周次、单双周与多时段

- 周次如 `1-16`、`第1-16周`、`1-16(单)`、`2-16周(双)`、`1,3,5`。
- 单双周可写在独立列（单/单周、双/双周、每周/全部/全周），也可写在周次片段里；片段自己的标记优先。`1-8单,10-16双` 会分别取单周和双周。
- 空白周次会报错，**空白不代表整学期**；不接受“整学期/全周”这类需要推断的写法。
- 节次单元格支持 `1-2`、`第1-2节`、`1-2,3-4`、`1~2；5-6`。每个分号/逗号片段拆成一条独立时段记录；同一行的多个时段不会静默合并。
- 单列“上课时间”支持 `星期一第1-2节`、`周一 1-2`、`星期三 5-6节`，多个时段用逗号/分号分隔；后续片段可省略星期，例如 `星期一1-2节,3-4节`。周次仍从独立周次列读取。
- 当前作息支持 **1–13 节**。老安装启动时会补种缺失的 11–13 节，但不会覆盖用户改过的时间；节次必须在当前作息表中，超出会明确报错，不会丢弃。
- 一行对应一个每周重复时段。同一课程多个时段请分行或使用多时段单元格；当前实现每个时段作为独立课程条目，可在课表逐条编辑/删除。不同内容可能撞课，请在预览中核对。完全相同的名称、星期、节次、周次、教师、教室记录使用稳定标识跳过。

## 登录后主动提取（不代存凭据）

工具：[tools/upc-schedule-export.user.js](../tools/upc-schedule-export.user.js)（Tampermonkey/Violentmonkey 用户脚本）。

流程：

1. 用户在学校统一认证中正常登录，打开本人课表页 `https://app.upc.edu.cn/site/weekschedule/*`。
2. 点击页面右下角“导出课表 CSV”。脚本使用浏览器现有会话，逐周读取**选定学期的全部周**，生成 CSV 并尝试复制到剪贴板；任何一周失败都会停止，不把当前周冒充整学期。
3. 回到 UPC Pocket：课表 → 导入 → 选择下载的 CSV，或“从剪贴板导入” → 预览 → 确认。

端点与字段来自学校课表页公开前端代码（2026-10-27 核验）：

- `GET /timetable/wap/default/get-index`
- `POST /timetable/wap/default/get-datatmp`，表单 `year`、`term`、`week`、`type=2`
- 响应 `d.classes` 为按天排列的 `c_1..c_14` 课程块，课程块含 `course_name`、`teacher`、`location`、`lessArr`

**适配范围与限制**：尚未在真实登录账号上完成端到端验证；没有取得真实登录 DOM/脱敏表头。若学校页面字段或结构变化，脚本会报错停止。模板与单元测试只能证明本地解析逻辑，不能宣称 UPC 实际导出格式已经验证通过。不要将含真实学生信息的 CSV 提交仓库或测试样本。

## 写入口径

追加导入至选择时的学期，不清空现有数据；同学期完全相同的记录跳过。预览后若学期或作息变更，会重新校验。写入失败整批回滚，不会留下半份课表。
