# UPC Pocket 0.1.8-preview

本次修复校园卡余额请求的 HTTP 406，保留已有图书馆功能，未修改课表。

## 已验证的根因

2026-10-28，在用户本人主动输入学号的普通 Chrome 测试页中，对同一账户、同一接口、相同表单、不发送 Cookie 进行对照：

| Accept 请求头 | 实际响应 |
| --- | --- |
| application/json | HTTP 406，HTML 错误页 |
| */* | HTTP 200，text/plain;charset=UTF-8，内容是 JSON；retcode=0，恰好一张卡，返回学号与本人输入一致 |

因此此次余额查询失败来自请求的内容协商设置。学校返回 text/plain 类型的 JSON；客户端不能要求服务器只返回 application/json。成功后仍严格解析 JSON、业务状态、所属学号和整数分值。

未保存本人请求参数、原始响应、余额或会话至本报告。没有登录、充值或其他写操作。
