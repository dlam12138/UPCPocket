## 当前状态

- M0.1 基线：完成。
- M0.2 插件契约与运行时：完成最小版本，包含 `core:plugin-api`、`core:plugin-runtime`、
  `core:plugin-ui` 与 Gradle 依赖边界检查。
- M0.3 平台/设计系统抽离与 AppGraph 收缩：未开始。
- M0.4—M0.7：未开始。

`app` 目前仍是唯一承载业务实现的模块；新 core 模块尚未被 `app` 依赖。不能据此声称
现有功能已经插件化。
