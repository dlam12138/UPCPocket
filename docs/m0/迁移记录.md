## 2026-11-03：M0.1 与 M0.2 最小版本

### 已完成

1. 固定重构前基线：`:app:assembleDebug`、`:app:testDebugUnitTest`、
   `:app:lintDebug` 全部通过；163 个测试通过；lint 0 error / 7 warning。
2. 落地两份交接方案到 `docs/`，同步 `AGENTS.md` 与 `docs/README.md` 的阶段说明。
3. 新增三个 Gradle 模块：
   - `:core:plugin-api`（Kotlin/JVM）：`PluginId`、`CapabilityId`、`CapabilityKey`、
     `PluginDescriptor`、`PluginDependency`、`PluginCapability`、`Plugin`、
     `PluginFactory`、宿主 API 版本。
   - `:core:plugin-runtime`（Kotlin/JVM）：注册、去重、宿主 API 校验、必需/可选依赖、
     依赖环检测、拓扑排序、能力声明核对、失败整体回滚、脱敏诊断。
   - `:core:plugin-ui`（Android/Compose library）：稳定入口/路由 ID、首页与更多页
     贡献、插件页面渲染契约、宿主导航接口、重复入口与缺失页面校验。
4. 根工程新增 `checkModuleBoundaries`：禁止 feature 实现互依赖、core 依赖 feature
   或 app、模块依赖 app；`plugin-api` 无内部依赖，`plugin-runtime`/`plugin-ui`
   只依赖 `plugin-api`。
5. 测试：
   - `:core:plugin-runtime:test`：9 个，覆盖依赖顺序、重复 ID、缺必需依赖、
     可选依赖缺失、依赖环、宿主 API 不匹配、创建失败无半注册、重复能力、
     声明/提供能力不一致。
   - `:core:plugin-ui:testDebugUnitTest`：5 个，覆盖排序、重复入口、缺失页面、
     重复路由、区块命名空间与顺序。

### 模块与依赖

```text
:app
  （当前尚未依赖新的 core 模块；业务仍全部在 app）

:core:plugin-api       无内部依赖，Kotlin/JVM
:core:plugin-runtime   -> :core:plugin-api
:core:plugin-ui        -> :core:plugin-api，Android/Compose
```

`plugin-api` 没有 Android 依赖，因此可以在纯 JVM 测试中验证注册与依赖规则；
Android Context、Repository 与页面仍由后续 feature 模块和宿主装配提供。

### 明确未完成

- `app` 尚未注册任何插件，也没有消费 `PluginUiSnapshot`；首页、更多页与导航仍是
  现有硬编码实现。
- 尚未创建 `feature:*` 模块。
- 尚无插件移除后的精简装配验证。
- 没有新增账号、密码、课表或任何校园接口调用。
- 未做设备覆盖安装、组件实例保留、Keystore 解密、WebView 会话验证。

### 复现命令

```powershell
.\gradlew.bat --no-daemon checkModuleBoundaries `
  :core:plugin-api:test :core:plugin-runtime:test :core:plugin-ui:testDebugUnitTest `
  :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

## 2026-11-03：M0.3 第一步（设计系统与平台加密）

### 已完成

1. 新建 `:core:designsystem`（Android/Compose library，无业务类型）：
   - `Theme.kt`、`MaterialYouScheme.kt`、`GlassCard.kt`、`RelativeTime.kt` 从 app 迁入；
   - 包名保持 `com.upcpocket.app.ui.theme` / `com.upcpocket.app.ui.components`，页面
     无需改调用点；
   - `DarkMode`、`ThemePreset` 移到 `com.upcpocket.app.designsystem`，`UiPrefsStore`
     仍按枚举 `name` 读写 DataStore，旧键值无需迁移；
   - 配色算法、组件尺寸、颜色与透明度未改动。
2. 新建 `:core:platform`（Android library）：
   - `SessionCrypto` 与 `KeystoreSessionCrypto` 从 `SchoolSessionStore` 迁入
     `com.upcpocket.app.platform.crypto`；
   - Keystore alias 仍为 `upcpocket.session.v2`，AES-GCM、12 字节 IV、Base64(NO_WRAP)
     格式不变；
   - `SchoolSessionStore` 只保留图书馆/电费业务的序列化与键名，加密实现改为依赖 platform。
3. `app` 显式依赖 `:core:designsystem` 与 `:core:platform`；新增 `checkModuleBoundaries`
   继续通过。

### 未完成

- `AppGraph` 尚未收缩；余额、电量、图书馆、专注仍由同一个全局容器暴露。
- `DOCK_CLEARANCE` 仍在宿主 `AppNav.kt`，等页面迁移时再确定归属。
- `SchoolWebCookies` 仍带 UPC 业务域名，暂留 app，待 library 迁移时再抽适配器。
- 未做设备上的主题、字体缩放、配色切换回归；只能确认编译与既有单测。

### 验证

```powershell
.\gradlew.bat --no-daemon checkModuleBoundaries `
  :core:designsystem:testDebugUnitTest :core:platform:assembleDebug `
  :app:assembleDebug
```

结果：`BUILD SUCCESSFUL`；designsystem 5 个配色测试通过；app 单测 158 个通过
（配色测试迁出后总数仍为 163）；platform 与 app Debug 构建通过；app lint 通过
（0 error，warning 由 7 降为 5，减少的是随 `RelativeTime.kt` 迁出的 2 条
ConstantLocale）。
