## 2026-11-03：M0.1 与 M0.2 最小版本

### 已完成

1. 固定重构前基线：`:app:assembleDebug`、`:app:testDebugUnitTest`、
   `:app:lintDebug` 全部通过；163 个测试通过；lint 0 error / 7 warning。
2. 落地两份交接方案到 `docs/`，同步 `AGENTS.md` 与 `docs/README.md` 的阶段说明。
3. 新增三个 Gradle 模块：
   - `:core:plugin-api`（Kotlin/JVM）：`PluginId`、`CapabilityId`、`CapabilityKey`、
     `PluginDescriptor`、`PluginDependency`、`PluginCapability`、`Plugin`、
     `PluginFactory`、宿主 API 版本。
   - `:core:plugin-runtime`（Kotlin/JVM）：注册、去重、宿主 API 校验、必需/可选依赖、
     依赖环检测、拓扑排序、能力声明核对、失败整体回滚、脱敏诊断。
   - `:core:plugin-ui`（Android/Compose library）：稳定入口/路由 ID、首页与更多页
     贡献、插件页面渲染契约、宿主导航接口、重复入口与缺失页面校验。
4. 根工程新增 `checkModuleBoundaries`：禁止 feature 实现互依赖、core 依赖 feature
   或 app、模块依赖 app；`plugin-api` 无内部依赖，`plugin-runtime`/`plugin-ui`
   只依赖 `plugin-api`。
5. 测试：
   - `:core:plugin-runtime:test`：9 个，覆盖依赖顺序、重复 ID、缺必需依赖、
     可选依赖缺失、依赖环、宿主 API 不匹配、创建失败无半注册、重复能力、
     声明/提供能力不一致。
   - `:core:plugin-ui:testDebugUnitTest`：5 个，覆盖排序、重复入口、缺失页面、
     重复路由、区块命名空间与顺序。

### 模块与依赖

```text
:app
  （当前尚未依赖新的 core 模块；业务仍全部在 app）

:core:plugin-api       无内部依赖，Kotlin/JVM
:core:plugin-runtime   -> :core:plugin-api
:core:plugin-ui        -> :core:plugin-api，Android/Compose
```

`plugin-api` 没有 Android 依赖，因此可以在纯 JVM 测试中验证注册与依赖规则；
Android Context、Repository 与页面仍由后续 feature 模块和宿主装配提供。

### 明确未完成

- `app` 尚未注册任何插件，也没有消费 `PluginUiSnapshot`；首页、更多页与导航仍是
  现有硬编码实现。
- 尚未创建 `core:designsystem`、`core:platform` 与 `feature:*` 模块。
- 尚无插件移除后的精简装配验证。
- 没有新增账号、密码、课表或任何校园接口调用。
- 未做设备覆盖安装、组件实例保留、Keystore 解密、WebView 会话验证。

## 下一步（M0.3）

1. 新建 `core:designsystem`：主题、`GlassCard`、相对时间、`DOCK_CLEARANCE` 等
   无业务组件；保持资源与视觉不变。
2. 新建 `core:platform`：Keystore AES-GCM、通用加密接口、学校 Cookie 清理与基础
   文件能力；不引用 `LibraryUser`、余额快照或课表实体。
3. 收缩 `AppGraph`：按功能拆分装配入口，页面/Worker/Service 不再直接读取全局容器。
4. 每步保持 `applicationId`、存储路径和组件 FQCN，并同时运行 app 测试与新增模块测试。
