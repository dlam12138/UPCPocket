## 2. 现有包与跨包依赖

当前只有一个 `:app` 模块，全部代码位于
`app/src/main/java/com/upcpocket/app/`。主要跨包依赖如下（重构时必须逐项拆解）：

| 依赖方 | 被依赖 | 说明 |
| --- | --- | --- |
| 页面、Worker、Service | `core.AppGraph` | 全局单例取 Repository、Prefs、Engine；M0 需收缩为宿主装配 |
| `AppGraph` | `data.*`、`focus.*` | 容器同时认识余额、电量、图书馆、专注，无法按功能裁剪 |
| `SchoolSessionStore` | `data.library.LibraryUser` | 通用加密与图书馆模型耦合 |
| `UiPrefsStore` | 主题、学号、楼栋/房间、记住登录 | 一个 DataStore 同时承载宿主偏好与业务输入 |
| `DirectCardBalanceSection`、`TangdaowanElectricityScreen` | `widget.WidgetUpdates` | 页面查询成功后直接驱动组件刷新 |
| `WidgetRenderer`、`WidgetUpdates` | 余额与电量两套模型 | 渲染器同时理解两个业务 |
| `PomodoroNotifications` | `MainActivity` | focus 反向依赖宿主 Activity |
| `LibrarySeatScreen` | ViewModel、会话恢复、页面 | 单文件承担三层职责 |
| `CampusServices`、`AppNav`、`HomeScreen` | 各自硬编码入口 | 同一入口在目录、导航和首页分别维护 |
| `FocusRepository`、`AppDatabase` | 7 张表（含 4 张旧课表占位） | 专注数据与旧表同库，schema 不可随意改 |

完整导入关系可由以下命令复现：

```powershell
Get-ChildItem app\src\main\java -Recurse -File -Filter *.kt |
  Select-String -Pattern '^import com\.upcpocket\.app\.'
```

## 3. 持久化文件与键

| 路径/名称 | 生产者 | 兼容要求 |
| --- | --- | --- |
| `noBackupFilesDir/card-balance-v1.json` | 余额快照 | 文件名、JSON 字段与含义不变；升级后旧缓存可读 |
| `noBackupFilesDir/power-reading-v1.json` | 电量快照 | 同上；仅成功查询写盘 |
| `databases/upcpocket.db` | Room v1 | 文件名、version=1、7 张实体表与 identity hash 不变；禁止 destructive migration |
| `datastore/ui_prefs.preferences_pb` | 宿主偏好 + 业务输入 | 文件名与键名不变；同一文件只能有一个 DataStore 实例 |
| `datastore/focus_prefs.preferences_pb` | 专注设置与运行快照 | 文件名、键名与序列化结构不变 |
| `shared_prefs/school_session.xml` | 图书馆 token、唐岛湾表单密文 | Preference 名、键 `library`/`power_form`、密文格式不变 |
| `shared_prefs/widget_state.xml` | 组件刷新状态 | Preference 名、`refreshing_*`/`error_*` 键不变 |
| WebView Cookie（学校域） | 学校页面会话 | 仍由系统 WebView 管理，不迁入加密存储 |

加密兼容：

- Keystore alias：`upcpocket.session.v2`；
- 算法：AES/GCM/NoPadding，12 字节 IV，Base64(NO_WRAP)；
- 解密失败只清对应条目，不崩溃、不牵连其他业务。

Room 兼容：

- 实体：`semesters`、`courses`、`course_sessions`、`display_overrides`、`periods`、
  `focus_tags`、`focus_sessions`；
- 前四张与 `periods` 是旧课表占位，DAO 已删除，但**不能**从 `@Database.entities`
  移除；`display_overrides` 同时被当前 schema 引用；
- 拆模块时保持实体全限定名、表名、字段与导出 schema 不变，并用真实数据库升级验证。

## 4. Android 系统组件与稳定标识

| 类型 | 全限定名/标识 | 兼容要求 |
| --- | --- | --- |
| Activity | `com.upcpocket.app.MainActivity` | launcher、singleTop、组件入口解析不变 |
| AppWidgetProvider | `com.upcpocket.app.widget.CardBalanceWidgetProvider` | 已放置组件实例依赖此 FQCN；`exported=false` |
| AppWidgetProvider | `com.upcpocket.app.widget.PowerWidgetProvider` | 同上 |
| Service | `com.upcpocket.app.focus.PomodoroService` | `foregroundServiceType=specialUse`，子类型 `pomodoro_timer` |
| Worker | `com.upcpocket.app.widget.WidgetRefreshWorker` | WorkManager 持久化类名与唯一任务名 |
| 唯一任务 | `widget-refresh-card`、`widget-refresh-power` | 已在队列中的任务升级后仍可解析 |
| 广播 action | `com.upcpocket.app.action.REFRESH_CARD_WIDGET`、`...REFRESH_POWER_WIDGET` | 既有 PendingIntent 继续有效 |
| 组件元数据 | `@xml/widget_card_balance_info`、`@xml/widget_power_balance_info` | 2×2、updatePeriodMillis=0 不变 |

系统组件运行约束：注册插件不得在启动时联网、登录、预约或增加轮询；组件只在用户
点击时入队一次性任务；失败保留上一次成功值与时间。

## 5. 测试归属与迁移要求

基线（重构前）的 163 个测试全部位于 `app/src/test`。迁移后测试已按所属 feature/core
拆分到各模块，实际数量和模块分布见[迁移记录](迁移记录.md)；`app:testDebugUnitTest`
不会自动覆盖库测试，全工程验证必须显式运行各模块测试任务。

基线覆盖范围：

- `data.classroom`、`data.ecard`、`data.library`、`data.local`、`data.power`、
  `data.repo`、`data.school`；
- `domain`（专注模型、统计、热力图、节次/课程遗留兼容）；
- `ui.school`、`ui.theme`；
- `widget`（刷新状态、组件意图与渲染）。

拆模块时测试随实现迁入所属模块；`app:testDebugUnitTest` 不会自动覆盖库测试，
全工程验证必须显式运行各模块测试任务。

3. Keystore alias 与密文格式；
