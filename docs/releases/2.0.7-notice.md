# UPC Pocket 2.0.7：小组件自动更新，余额显示更完整

状态：公告草稿，待用户审核；本版本尚未公开发布。

这次更新主要改善桌面小组件和校园卡的使用体验：

- **课表小组件自动更新**：根据已同步的课表，在上下课和跨日时自动调整显示，减少手动刷新。
- **校园卡小组件自动更新**：联网时每 30 分钟尝试更新余额；课表和校园卡小组件移除刷新按钮，点击整张卡片仍可进入应用。
- **余额显示更完整**：校园卡页面与小组件的主金额改为“卡内余额 + 过渡余额”，下方小字单独标注过渡余额。
- **改善校园卡连接**：针对部分设备的余额、流水查询连接问题增加恢复处理，完善充值准备读取与网络诊断，方便定位问题。

小组件更新可能受系统省电与后台限制影响而延后；首次使用课表或尚未同步的新教学周，仍需先在应用内刷新课表。电量小组件保留手动刷新。

安装包约 **5.40 MiB**，支持 **Android 12 及以上**。发布后，已安装新版 2.0.4–2.0.6 的同学可在“设置 → 关于 UPC Pocket”检查更新，或下载正式 APK 覆盖安装，无需卸载。已安装 2.0.7 测试版的同学，请手动下载正式包覆盖安装；旧版 2.0.3 继续保留，数据不迁移。
