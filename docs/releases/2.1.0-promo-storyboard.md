# 《从早八到晚自习》｜UPC Pocket 2.1.0 功能预览

建议成片 **3 分 06 秒，1920×1080，30 fps**。用一条待办串起一天。开场，首页上有「高等数学 A」和「整理高等数学笔记」。结尾，学生在专注页勾掉这条待办，再从桌面看下一天的课。这两个名称都来自仓库现有的合成样例，可以直接拍。

按本地 `main` 的 HEAD `f9e7a37` 核对，2.1.0 仍标为开发中，默认构建版本名仍为 2.0.9。片头、封面和片尾统一写 **「2.1.0 功能预览」**。首页、课表、服务、专注四项导航必须取自当前宿主。[更新日志](../../docs/CHANGELOG.md) · [2.1.0 更新计划](../../docs/design/2.1.0-update-plan.md) · [项目 README](../../README.md) · [构建配置](../../app/build.gradle.kts)

### 录制时最值得留住的画面

- **必须用真 UI 的转场**是图钉固定后首页出现同一入口、同一条待办更换位置、地图切换步行与骑行、体育馆与泳馆的两个不同弹窗，以及系统桌面的本周课表。每个点按前留半秒，结果出现后留两秒。这样静音观看也能理解操作。
- **课表转地图有一个已核实的拍摄限制。** 正式宿主给课程详情传入地图动作，现有 `TimetablePreviewActivity` 的合成详情没有传这个动作。若离线宿主拍不到该按钮，就从真实详情的「地点」一栏切到独立的真实地图搜索，用画外字「课程地点可在校园地图查看」。不要在预览页上补画按钮或假装点击。[合成课表预览](../../feature/timetable/src/debug/kotlin/com/upcpocket/app/timetable/TimetablePreviewActivity.kt) · [课程详情实现](../../feature/timetable/src/main/kotlin/com/upcpocket/app/timetable/TimetableScreen.kt)
- **真界面使用合成课表、教室、座位、金额或记录时，角标写「演示数据」。** 没有合成样本的业务保留真实入口或未同步状态。4×4 周组件若只能拍到缺缓存提示，就展示真实组件，再在手机框外给七列排布的「布局示意」。前台转向、偏航可用独立箭头图注明「导航示意」，手选路线保持「路线预览」。地图裁切后保留 `© OpenStreetMap contributors`。[组件设置实现](../../app/src/main/java/com/upcpocket/app/ui/settings/WidgetSettingsScreen.kt) · [地图数据与许可](../../docs/adr/007-offline-campus-navigation.md)
- **外部业务收镜点**分别是校园卡充值入口、场馆交接弹窗、系统拨号器、图书馆预约记录入口。公开网页只用已有、可离线播放的公开画面。学校账号页有截图保护，关于页只裁到 QQ 群卡，「支持开发」整块排除在正片、封面与转场取样之外。[隐私说明](../../docs/PRIVACY.md) · [场馆交接实现](../../app/src/main/java/com/upcpocket/app/ui/official/GymReservationHandoff.kt) · [官方入口记录](../../docs/upc/官方入口.md)

### 给 Remotion coder 的执行顺序

1. **先锁旁白与素材表。** 复用工作区现有 `media/promo-2.1.0` 工程、30 fps 设置和按音频实测生成时间线的脚本。上表时间是剪辑预算。改词后用新音频段 ID 或强制重制，避免脚本按旧文件名复用旧配音。两处旧文案尤其要换掉，图书馆刷新读取的是开放**日期与馆区**，全应用也包含充值与预约入口，片尾「只读」只适用于石光和 e站通。[配音脚本](../../media/promo-2.1.0/scripts/make_vo.py) · [时间线脚本](../../media/promo-2.1.0/scripts/build_timeline.py)
2. **录屏和配音可并行，锁音后再精剪。** 普通话用平常向同学介绍应用的语气，每个「／」换一条字幕，单条一至两行。字幕从同一份分段时间导出烧录版与 SRT。音乐压在人声下，片头、点图钉和勾掉待办三处留一点声音空间。
3. **画面以看清一次操作为准。** 用米白底、墨绿文字和少量湖蓝。全机位交代入口，随后用同一份实拍裁切放大控件。常规转场 8–12 帧，地图路线、场馆菜单、七列周课表各留至少两秒静止。字幕避开底栏、按钮和地图署名。
4. **交片核对两遍。** 静音看一遍，确认所有表内功能都能辨认，四个 tab、五类组件、两个场馆菜单准确，赞赏二维码零帧出现。再带声看一遍，核对口播、字幕、按钮动作同步，片中没有 CAS、支付、预约成功或实地导航实测画面。交付 MP4、同时间线 SRT 和无二维码封面。

这份导演稿用于录制与剪辑。三分零六秒是建议片长，最终帧数以普通话实录为准。模拟器录屏完整性与成片声画同步留待主会话按素材核验。
