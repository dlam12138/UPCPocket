# UPC Pocket 2.0.5 重大更新公告

2026-11-14

UPC Pocket 2.0.5 正式发布！这次新增石光第二课堂和 e站通，也集中修复了校园服务自动登录问题。

**新增石光第二课堂**

支持活动搜索、分页和详情，查看五模块学分学时及本人参与记录。当前页可按校园活动、社会实践筛选，也可以隐藏已结束活动；查看详情后返回，保留列表位置。

**新增 e站通**

搜索办事事项、阅读办事指南，查询本人的待处理和在办。页面增加登录状态与“登录 / 重试登录”入口，保存学校账号后可自动尝试登录。

**修复自动登录与验证提示**

修复课表、流水、石光和 e站通的自动登录问题，纠正普通登录页被误判为需要验证码的情况。石光学校验证页在深色模式下更清晰，未自动返回时可以手动继续。

**流水按月查询更方便**

年月点选替代手动输入，支持跨年选择；取消选择保留原筛选。完成学校网页登录后，回到当前日期筛选的第一页继续查询。

**登录问题更容易定位**

诊断报告增加登录过程和失败阶段信息。遇到问题时，可在设置的关于页导出诊断报告；报告不包含账号密码、Cookie 或个人业务内容。

石光与 e站通本次提供只读查询；活动报名、签到和办事申请提交仍请使用学校官方平台。
