# UPC Pocket 2.0.5 · 重大更新

状态：2026-11-14 用户验收并授权正式推送，已公开发布至 [GitHub Release](https://github.com/dlam12138/UPCPocket/releases/tag/v2.0.5)，设为 latest。发布时间为 2026-11-14 11:55:20 UTC（北京时间 19:55:20），发布源码为 `3fc57a08770fd798b81cb3562cfe0860c6509eed`；旧版更新线路继续指向 2.0.3。

版本：2.0.5 / versionCode 26，应用标识 `com.upcpocket.next`，Android 12 及以上。此次重大更新新增石光和 e站通原生只读服务，完善校园卡流水，并修复多项校园服务自动登录。

## 新增石光第二课堂

- 首页增加“石光 / 活动与学时”入口，提供“活动”和“我的”两个页面。
- 支持活动关键词搜索、分页和原生详情；查看详情后返回保留列表位置。
- 当前页可按“全部 / 校园活动 / 社会实践”筛选，默认开启、可关闭“隐藏已结束”；仅隐藏结束时间明确且已过期的活动，时间未知的记录保留。筛选只作用于本页，筛空后仍可翻页。
- “我的”提供五模块学分、学时与本人参与记录。缺失数值显示未知，不据累计值推断学校要求、剩余或是否达标。
- 使用已保存学校账号完成受控认证；个人记录读取前核验会话归属。活动和个人结果只保存在内存，换号或会话失效后撤下旧结果。
- 提供学校网页登录回退；未自动返回时可手动继续，经当前账号与请求核验后恢复原查询。
- 本次为只读能力，不提供活动报名、取消、签到或成绩明细导入。

## 新增 e站通办事服务

- 首页增加 e站通入口，提供“事项 / 待处理 / 在办”三个页面，与本机待办分开。
- 事项支持名称、部门及多关键词搜索、分页和原生办事指南；指南展示来源提供的办理信息、材料及表单说明。
- 支持本人待处理和在办申请读取，明确展示零值、未知进度及未完整加载的范围。
- 保存学校账号后保留进页自动认证，增加“登录 / 重试登录 / 学校账号”入口和登录状态。
- 认证失败时，只有支持公开访问的目录或指南可显示公开范围，个人队列始终要求认证。新增功能不提交申请、审批、撤回或附件。
- e站通暂不支持网页登录后接管原生会话；遇到真实验证码或二次验证会停止自动提交，不循环重试密码。

## 校园卡流水更易操作

- “按月”改为年月点选，无需输入 `YYYY-MM`；支持前后切年及点击年份选择。
- 切年、选月先修改草稿，确认后才应用；取消保留原筛选，相同月份确认保留已加载结果，换月后等待主动查询。
- 流水窗口保留稳定的“网页登录”入口，确认需要验证时显示“前往验证”，无需反复点击原生登录试出入口。
- 完成学校验证并核验本人归属后，回到原生流水，仅读取当前日期筛选的第一页；“加载全部”继续由用户主动触发。
- 完善重复回调、页面关闭、账号变化与浏览器清理的处理，拒绝旧页面结果覆盖当前账号。

## 修复自动登录与验证提示

- 修复较长的学校普通登录表单被客户端提前拒绝的问题；课表、校园卡和石光共用同一字段校验，保留有界长度与目标校验。
- 修复 e站通将成功响应中的数组误当整数、导致认证成功后仍判失败的问题。
- 区分普通密码表单、确认验证码、二次验证、明确拒绝与未知拒绝，避免把普通登录页或隐藏占位统称为验证码。
- 校验通过的普通登录表单最多提交一次密码；遇到挑战、提交后未知结果或明确失败时停止自动重交。复用失效会话时保留一次有界恢复。
- 统一学校账号、凭据代次与 CAS 基础设施，保留各业务自己的回跳、Cookie 和会话归属处理。
- 修复石光学校验证页在深色主题下标题、返回按钮的可读性，完善未自动返回时的手动继续入口。

## 登录诊断更完整

- 导出诊断增加课表、流水、石光、e站通的凭据恢复、表单识别、密码是否提交、挑战证据、回跳及业务会话阶段。
- 补充固定 HTTP、MIME、结构和停止原因分类，便于区分“未提交密码”“学校要求验证”和“认证后业务检查失败”。
- 同次操作使用短随机 operationId 关联，账号或诊断清理后拒绝迟到记录；记录失败不影响业务。
- 沿用关于页的主动导出和清除入口。报告不包含账号密码、Cookie、Token、URL、HTML、响应正文或个人业务内容。
