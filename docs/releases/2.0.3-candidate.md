# UPC Pocket 2.0.3 使用引导候选

本地候选，尚未发布。基于已发布 2.0.2 的 main（`d338fe6`），versionName `2.0.3`、versionCode `24`。正式下载入口和更新源继续保持 2.0.2。

## 改动

- 学校账号保存成功后提示“已保存，尚未验证。返回课表后，点击右上角刷新。”不将本机保存当作登录成功。
- 课表首次使用和保存/换号后的等待查询状态说明下一步；读取成功后等待刷新提示消失。学校网页验证、未读取学期和未查询周保留对应提示。
- 唐岛湾电量按楼号、房间填写情况提示查询；组件页说明先查询、添加、刷新和点击主体返回。
- 使用指南放在已有的“设置 → 关于”，没有新增设置目录或引导弹窗。

模拟器冷启动期间曾出现 System UI 无响应对话框，选择等待后恢复；应用随后冷启动和界面操作正常。视觉与组件验证期间关闭模拟器网络，结束后恢复原来的网络、字体和深色设置。
