# UPC Pocket 2.0.3 使用引导与空闲教室候选

> 本文为开发阶段记录；成果已纳入 [2.0.3 正式版](2.0.3.md)。下文“未发布”等描述保留当时现场，最终交付以正式发布记录为准。

本地候选，尚未发布。基于已发布 2.0.2 后的 main（引导提交 `c427696`），versionName `2.0.3`、versionCode `24`。正式下载入口和更新源继续保持 2.0.2。

## 改动

- 学校账号保存成功后提示“已保存，尚未验证。返回课表后，点击右上角刷新。”不将本机保存当作登录成功。
- 课表首次使用和保存/换号后的等待查询状态说明下一步；读取成功后等待刷新提示消失。学校网页验证、未读取学期和未查询周保留对应提示。
- 唐岛湾电量按楼号、房间填写情况提示查询；组件页说明先查询、添加、刷新和点击主体返回。
- 使用指南放在已有的“设置 → 关于”，没有新增设置目录或引导弹窗。
- 空闲教室只记住上次校区，不恢复上次日期或时段；每次真正进入页面初始化上海时区今天、上午和全部教学楼，读取校区后只发一次初始查询。
- 预设模式切换校区、有效日期或上午/下午/晚上自动查询；自定义节次保持手动“查询”，切回预设恢复自动。同一查询键正在查询或已有成功结果时不重复请求，没有定时轮询；日期选择取消不发请求。
- 移除日期区“今天”快捷按钮，保留日期选择与前后一天。请求取消和代次隔离、失败/无完整响应不显示空闲、`d.js` 空闲交集语义与完整查询键缓存保持不变。
- 关于页使用指南同步为“记住上次校区、预设自动查询、自选节次后点查询”的短文案。
