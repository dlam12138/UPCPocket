# UPC Pocket 2.0.8 · 新增服务页和待办小组件

- **服务更好找。** 底部现在有首页、课表、服务、待办和专注五个页面。常用服务可以搜索、按分类浏览，也可以固定到首页。在「服务 → 学习」可以打开教务处官方校历。
- **课表和桌面课表。** 应用内保留紧凑的周视图，长课名用省略号显示，点开课程可查看全名。桌面课表在空间足够时会显示后续课程。
- **待办新增截止时间。** 截止与提醒可以分别设置。把待办加到桌面后，可以点开事项、勾选完成，或点「＋」新建。
- **图书馆选座新增布局图。** 唐岛湾、古镇口东区和求是都可在座位列表和布局图之间切换。布局图支持放大、拖动和复位。
- **校园卡与流水。** 兼容更多学号格式，消费分类占比按已加载的支出计算。研究生账号的学校端查询与充值准备仍待实测。
- **桌面小组件新增可选外观。** 校园卡余额、唐岛湾电量、今日课表和待办各有一个使用静态磨砂材质的「玻璃版」，可从系统桌面小组件列表添加。参考图中的玻璃质感列入长期计划。 [反馈与进展](https://github.com/dlam12138/UPCPocket/issues/6#issuecomment-6971226080)

安装包约 **5.78 MiB**，支持 **Android 12 及以上**。已安装新版 2.0.4–2.0.7 的同学可在「设置 → 关于 UPC Pocket」检查更新，也可以下载 APK 覆盖安装。已安装同包名、同长期签名的 2.0.8（29）候选包，可手动覆盖安装。旧版 2.0.3 可与新版共存。
