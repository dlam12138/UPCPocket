## 已实现的变化

- 首页缩小日期、移除问候，完整今日课程移至顶部，收紧待办摘要和服务入口，保留校园卡操作。课表插件缺失时，首页区块、tab 和路由一致缺省。
- 今日课程从当前账号的本机缓存恢复，使用上海实际日期，独立于查看周，不为首页恢复调用联网查询。补齐跨周／跨学期定位、有界账号恢复、跨日和迟到读写守卫；无课、未同步、缓存不可读和账号不可用分别显示。首页与周网格共用课程详情，刷新后解析最新字段，失效时关闭。
- 空闲教室重排直接条件、详细筛选、查询状态和楼栋房间结果。筛选草稿可取消、原子应用；保留预设自动查询、自选／楼栋手动查询、快捷组叠加及去重。卓越 A/B 与仅看空闲继续本机过滤，同条件失败保留带时间的结果，不同查询键不混显。
- 设置分组收紧，图书馆登录默认一行，展开／收起不改变会话和记住登录开关。账号与共用摘要显示“已保存”，保留内部 `SAVED_UNVERIFIED`、业务独立认证、安全窗口、确认密码、密码清空和真实错误／清理状态。
- 待办增加完成反馈与列表过渡，完成和撤销使用任务 revision 校验，协调提醒并处理取消窗口；已有新增、编辑、删除及撤销继续保留。电量、流水、图书馆、石光和 e站通收紧条件与结果层级，保留搜索、分页、登录回退和异常状态。

首批界面更新保留现有 Compose / Material 3、手动插件装配、Room / DataStore、OkHttp、RemoteViews，以及 AGP 8.7.3、Kotlin 2.0.21、Compose BOM 2024.12.01、Gradle 8.9、minSdk 31、compile/targetSdk 36；当时未增加校园接口、写操作或框架迁移。

通过 Lody 使用 planner、researcher、三组独占文件的 coder、集中 tester 和独立 reviewer。审查发现的今日缓存代次、详情过期、流水账号隔离、待办取消协调和账号异常摘要问题均已交回 coder 修复并复核。主协调者核对原始日志、XML、哈希及截图，不以角色声明代替验证。
