# UPC Pocket 新版更新：校园日常更顺手，小组件自动更新

**2.0.7 已正式发布，以下合并介绍 2.0.6 与 2.0.7 的更新内容。**

这次把 2.0.6 和 2.0.7 的更新一起介绍给大家：

- **首页更清楚**：今日课程放到首页顶部，待办与常用服务更紧凑；课表网格、课程详情和查询结果更易查看。
- **查询更顺手**：空闲教室重新整理常用条件、详细筛选和楼栋/房间结果，保留两校区及古镇口卓越 A/B 筛选；图书馆登录默认收起，需要时展开。
- **校园卡支持微信充值**：输入金额、点击充值，即可拉起微信，实际付款在微信内确认；同时改善部分设备的余额、流水查询连接，完善充值准备读取与网络诊断。
- **桌面小组件自动更新**：课表根据已同步课程，在上下课和跨日时调整显示；校园卡联网时每 30 分钟尝试更新余额。两个组件移除刷新按钮，点击整张卡片仍可进入应用。
- **余额显示更完整**：校园卡页面与小组件显示“卡内余额＋过渡余额”的总额，下方小字单独标注过渡余额。

安装包约 **5.40 MiB**，支持 **Android 12 及以上**。已安装新版 2.0.4–2.0.6 的同学可检查更新，或直接下载覆盖安装，无需卸载；已安装 2.0.7 测试版的同学，请手动下载正式包覆盖安装。旧版 2.0.3 可继续保留，与新版共存，数据不迁移。
