## 实现

- 古镇口东区（seat）和求是（seatengine）房间页默认按座位选，顶部馆区/日期、两模式切换、并列起止控件、列表状态/重试、选座摘要、固定底栏与二次确认对齐唐岛湾。
- 实际复用 `TimeRangeControls`、`SeatCandidateRow`、`SeatSelectionBottomBar`、`HiddenSeatManagementSheet`，没有复制一套预览 UI 冒充生产。保留真实 Float 坐标、旋转与地图横纵滚动。
- 按时段找只点查找后读取当前房间的真实区间占用。完整真实座位集合排除区间占用和 `isReserve=0` 禁用项；缺字段、失败、未知或不完整集合不可宣称全可约。没有 libseat 接口、分页、time-id 或逐座全馆扫描。
- 本机隐藏区分 `libseat / chaoxing-seat / chaoxing-seatengine`、固定租户/馆区、房间和官方座号。旧 libseat 方法与 DataStore 格式兼容；原子 edit，失败不报成功。隐藏立即清选，撤销不复活选择，地图弱化并标记，房间内逐项/全部恢复；退出/换号不删偏好。
- 查询、隐藏、预检与提交均检查账号/会话、房间、日期、模式、时段和请求代次；同 Cookie 新会话也通知失效；Cookie 固定绑定原核验账号与会话代次，新账号门闩不能将其重新认领，旧读取失效也不能清掉新会话。预检重读房间规则和区间占用，真正 POST 前再次校验；原 submit_enc/enc/tenant 参数保留，验证码才回官方页。
- Unknown 防重在 Service 内存的真正 POST 边界登记，跨关闭详情/新 ViewModel 生效；POST 前网络失败/验证码不误登记。**进程重启或重新建立会话不保证保留**，不能宣称持久幂等。
- 保持现有 Compose/Material 3、AppGraph、RemoteViews、学校 CAS/本人核验、账号清理门闩、WebView MATCH_PARENT 与允许列表。未新增研讨间，未改热力图、待办/Pager、组件或更新器实现。
