## 今日课程在前，常用操作更紧凑

- 今日课程移到首页顶部，保留当天完整课程、上课中/下一堂状态和课程详情；日期缩小，待办摘要与校园服务收紧。

## 校园卡微信充值

首页校园卡区进入“充值”，使用已保存的学校账号核验本人卡。正常操作为 **输入金额 → 点击带金额的微信充值按钮 → 拉起微信**，实际付款在微信内确认，不再叠加一次金额确认。

- 下单前检查微信可用性并重新读取规则；明确的动态上下限、整数/仅预设限制继续生效。
- 兼容学校返回空额度配置，采用有官方源码依据的 UI 输入默认和前端配置覆盖顺序；不将 UI 默认当作服务端额度承诺。
- 保留账号/凭据代次守卫、加密待查订单、单次下单和结果未知时防重。回来只读查学校订单，回跳或成功拉起微信不等于付款成功。
- 异常恢复保留带后果的确认；清除本机防重标记不取消学校订单、不退款。

感谢 [PR #5 作者](https://github.com/dlam12138/UPCPocket/pull/5) 贡献原生充值实现。本地以 `085ff43` 保留原作者提交归属，后续简化交互并完成会话失效、标记持久化及空额度兼容修复。原型演示与本包验证分别记录。
