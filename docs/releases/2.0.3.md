## 本次更新

- **待办与一次性提醒**：独立待办页，支持添加、编辑、完成、删除与撤销；通知可完成、稍后 10 分钟或打开对应任务。首页同步展示未完成数量和近期两项任务，换学校账号不丢个人待办。
- **四项滑动导航**：首页 / 课表 / 待办 / 专注可整页左右滑动，底部胶囊与手势进度联动，点击平滑切页；保留滚动位置，二级页、键盘和编辑面板不误切页。浮动导航基于 ZZUPocket 的 MIT 代码适配，见 [来源说明](../third-party/ZZUPocket-dock.md)。
- **空闲教室更顺手**：记住上次校区，每次进入默认今天上午；切换校区、日期、上午/下午/晚上自动查询，自选节次保留手动查询。移除无效的“今天”按钮，迟到请求不覆盖新条件，查询失败不显示假空闲。
- **首次使用引导**：保存学校账号后提示返回课表点右上角刷新；课表、寝室电量和桌面组件显示必要的下一步，关于页补充使用指南。
- **图书馆按时段找座位**：房间内保留“按座位选”，新增“按时段找”；先选日期和起止时间，再查当前房间，手动加载更多。区分无候选、部分加载失败与完整结果，候选选择后匹配学校实际时间选项，提交前再确认。
- **个人隐藏座位**：不喜欢的位置可在本机隐藏，支持撤销、管理和恢复；列表过滤、地图弱化，不修改学校座位状态，也不上传偏好。

## 感谢 Issue #1：先适配唐岛湾

感谢 [@kujochisaki3378](https://github.com/kujochisaki3378) 在 [Issue #1](https://github.com/dlam12138/UPCPocket/issues/1) 提出的“先选时间、再找座位”和个人拉黑座位建议。

本轮**先对唐岛湾 libseat 适配**：使用学校实际的 `searchSeats` 时段查询，而不是把当前座位图的空闲状态当作未来时段可约；只查当前房间，按服务端分页加载；“拉黑”落实为可恢复的本机个人隐藏。古镇口东区、求是使用独立超星协议，仍沿用原流程。本轮没有增加安静度、采光或电源排序，也不把个人隐藏认定为座位故障。

## 安装与提醒

2.0.2 用户可在“设置 → 关于 UPC Pocket → 检查更新”升级；2.0 用户需手动覆盖安装一次。保留现有应用证书与数据，无需卸载。待办提醒需通知权限，精确闹钟未授权或系统限制后台时可能延后；系统强行停止后需重新打开应用恢复。
