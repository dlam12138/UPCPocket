## 2026-11-18 应用主题与桌面外观决定

用户已确认此前修改的原组件通过验收，并要求单独添加玻璃版。原组件沿用现有外观设置，新增的校园卡余额、唐岛湾电量、今日课表与待办玻璃版使用固定半透明底色、描边和高光。桌面选择由 Provider 身份决定，两种版本共用原有数据、更新和交互。用户要求 2.0.8 仅在效果完整且达到原主题流畅度时保留 App 内新主题。

原候选在 API 36 模拟器上的同场景样本显示，玻璃模式 26 / 26 帧卡顿，P95 为 550 ms，Material 3 为 6 / 145 帧卡顿，P95 为 18 ms。修复候选已减少普通卡片与导航的实时采样。计数清零后针对该候选的玻璃样本仍为 39 / 39 帧卡顿、P95 900 ms，原始文件为 `device-smoke-ui-fix-2026-11-17/root-glass-v2-framestats.txt`，操作记录为 `root-glass-v2-actions.jsonl`。这些数字来自短时模拟器测量，用户手机证据为实际卡顿反馈。

最后一次 Dock 实验移除了重滤镜，构建退出码为 0，设备对照未完成。构建记录为同目录的 `root-final-dock-release-exit.json`，原字节归档为 `app-release-final-dock-unverified.apk`，SHA-256 为 `7099848349FFF42C03D023DDC9F3EBED4C774A457CFFD1F534D35BA8627723C5`。本轮另建候选路径，保留该包与此前两份候选。

共享背景或缓存绘制对象可以减少重复工作，滚动内容的实时模糊与透镜折射仍需处理变化的输入。静态、降采样或仅交互时启用会改变完整效果。Haze 的 Pixel 8a 测量显示部分玻璃场景有帧预算余量，密集滚动网格会超出 60 Hz 帧预算。它的实验性原生背景路径要求 SDK 37.2，超出当前 SDK 36 基线。现有证据不足以交付同时满足两项条件的全局主题，因此 2.0.8 使用 Material 3，移除实验主题及其 Kyant 运行时依赖。[Haze 性能测量](https://chrisbanes.github.io/haze/2.1.0/performance/)、[Android RenderEffect](https://developer.android.com/reference/android/graphics/RenderEffect)、[基础小组件](https://developer.android.com/develop/ui/views/appwidgets)、[Kyant 来源记录](../research/2026-11-17-2.0.8-dependency-provenance.md)
