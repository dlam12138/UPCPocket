日程待办卡片默认在「课表」页顶部，可在「设置 → 应用 → 日程待办位置」改到「专注」页计时控制下方。位置保存在本机，周课表继续在「课表」页查看。
新增「校园地图」，可从服务页进入或固定到首页，课表详情可打开地图核对地点。新增「校园通讯录」，可查办事窗口、电话和地址。
可搜索校内地点、比较步行和骑行路线；启用前台定位后，沿路显示转向、剩余距离并在确认偏航后重新规划。古镇口西区道路覆盖待补，楼门和通行以现场为准。
教务系统等校园官方网页可固定到首页「常用服务」。在「服务 → 官方网页」点击图钉固定或取消。
新增「体育馆预约」和唐岛湾「游泳馆预约」，可查看学校预约规则或场馆介绍。
在「服务 → 校园生活」或「校园官方网页 → 生活」打开入口，可一键复制「中国石油大学体育场馆」公众号名并打开微信。余位和预约结果在微信内查看。
「设置 → 关于 UPC Pocket」新增 QQ 交流群和微信赞赏码。可复制群号、查看和保存赞赏码，赞赏自愿。
