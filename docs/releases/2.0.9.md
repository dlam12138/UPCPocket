### 次序与附件

用户确认 APK 和公告后，用仓库外的 `UPCPOCKET_UPDATE_PRIVATE_KEY` 签新线清单。当前环境缺少该路径，`update-next.json`、`update-next.sig` 和发布用 `SHA256SUMS.txt` 待生成。

设为 latest 时，同批发布 `UPC-Pocket-2.0.9.apk`、`update-next.json`、`update-next.sig`、`SHA256SUMS.txt` 和旧线 `update.json`、`update.sig`。校验表覆盖 APK 及两套清单和签名。旧线两件附件已从 `v2.0.3` 下载，SHA-256 与 2.0.8 同名附件一致，OpenSSL 验签通过，继续指向 `com.upcpocket.app` 的 2.0.3 / 24。正式公开前复核草稿附件的大小、哈希与两套签名，公开后检查官方及主加速线路。 [旧线来源](https://github.com/dlam12138/UPCPocket/releases/tag/v2.0.3) · [更新机制](../updates/README.md) · [ADR 004](../adr/004-release-identity-and-update-trust.md)

## 实际验证

- `:app:assembleRelease` 成功，R8、资源收缩、`lintVitalRelease` 已执行。检查了 APK、merged manifest 和 Release 配置，生产包排除 Debug 预览与更新测试源。R8 日志保留微信 SDK 警告。
- API 36 模拟器由 rc4 / 33 用 `adb install -r` 升至 2.0.9 / 34，保留首次安装时间与轻量玻璃偏好。首页启动成功，日志中的崩溃和 ANR 均为 0。已比对安装字节与待发 APK 的哈希。
- PR #13 的 54 项课表定向单测以及 rc4 的首页滚动、底栏切页、待办浮层冒烟已通过。API 31–32 的底栏回退、真机性能与真实校园预约尚待验证。
- 宣传图为 1920 × 1080，使用离线验收包界面。二维码在原尺寸与 960 × 540 缩图均解码至 `v2.0.9` Release。

本地构建、成品校验、升级和二维码证据存于 `.local/verification/2.0.9-release-prep/`。准备过程对照[构建指南](../BUILD.md)、[发布脚本](../../tools/release_update.ps1)和[上一版发布记录](2.0.8.md)。
