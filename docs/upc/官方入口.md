# UPC 官方入口清单

学校：中国石油大学（华东）。整理日期：2026-10-27。

来源：主项目根目录的 `官方入口.txt`。原文件保留在本机；本清单去除了微信 code、token、state 和空值回调参数。根目录原始文件已加入 Git 忽略规则，不将个人临时链接提交到仓库。

## 功能入口

| 项目功能 | 固定入口 | 本轮匿名检查 | 下一步 |
| --- | --- | --- | --- |
| 课表 | https://app.upc.edu.cn/site/weekschedule/index | HTTP 200；仅确认前端页面响应 | 核实本人正常登录后的学期、课表请求及整学期范围 |
| 空教室 | https://app.upc.edu.cn/freeclass/wap/default/all | HTTP 200，标题“空闲教室” | 核实筛选参数、真实教室数据和登录要求 |
| 唐岛湾电费 | http://dfcz.upc.edu.cn/ShiYou/Default.aspx | 跳转微信 OAuth 授权页 | 验证微信内正常打开路径及本人只读余额；不能保存一次性的 code |
| 古镇口电费 | https://gzkdf.upc.edu.cn/acmswx/index.aspx | TLS 证书校验失败，原因是证书过期 | 核实证书修复或学校提供的新入口；校内业务状态待确认 |
| 图书馆座位 | https://libspace.upc.edu.cn/libseat/ | HTTP 200，标题“座位预约系统” | 对照已有 UPC 研究核实 CAS、馆区、座位和预约状态 |
| 超星空间预约入口 | http://v1.chaoxing.com/wechatSet/mobileIndex?type=0&fidEnc=adde45d877b35a43&pageId=6833 | HTTP 200，标题“空间预约” | 确认与学校图书馆座位服务的关系及适用馆区，暂不与 libseat 合并 |
| 校园卡余额 | http://jhzf.upc.edu.cn:20081/wechat/query/balance.html | HTTP 200，但标题“操作错误”，不是有效余额页 | 通过校园卡服务大厅进入，核实微信登录上下文与只读查询 |

本轮检查只访问无个人凭据的入口，没有登录、查询个人余额、预约或充值。HTTP 200 不等于业务成功；本机证书错误也不能推断系统停用。未关闭 TLS 证书校验。

## 供项目读取的配置

[official-entrypoints.json](official-entrypoints.json) 提供七个入口的稳定 ID、功能分组、校区、地址、来源和核查状态。它是开发用的入口台账，本次没有把旧 Android 代码中的郑大地址替换成 UPC 地址，也没有将这些网页地址当成已接通的原生 API。

| 功能分组 | 稳定 ID |
| --- | --- |
| 课表 | `schedule` |
| 空教室 | `free_classroom` |
| 电费 | `electricity_tangdaowan`、`electricity_guzhenkou` |
| 图书馆 | `library_seat`、`library_chaoxing` |
| 校园卡 | `campus_card_balance` |

唐岛湾与古镇口先保留为不同数据源；超星和 libseat 保留为不同入口。两个系统是否共享账号、会话或业务数据，需要 UPC 证据确认。

## 第三方参考

用户提供的 [astrbot_plugin_upc](https://github.com/kujochisaki3378/astrbot_plugin_upc) 是第三方实现参考，不是官方入口或学校授权依据。2026-10-27 对固定提交 `a4bac417f3df284957c27dc8aee8d51d011f5b41` 的 README、MIT 许可证及课表/图书馆认证与会话相关源码做了只读检查；未运行插件或做真实账号验证。课表 Cookie 复用、图书馆业务 token 验证及 `params.startday` 可作线索；没有电费/校园卡实现，明文保存密码或 token 的做法不采用。具体位置与验证边界见 [下一步开发指令](下一步开发指令-暂停后续接.md)。
