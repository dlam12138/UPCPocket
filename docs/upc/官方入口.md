## 课表来源与验证边界

课表协议、认证流程和严格解析参考本地 [UPC-MCP](https://github.com/dlam12138/UPC-MCP) 固定提交
`948f5f21ad7a12fd94b53403a07ac867209f7700`（MIT，Copyright (c) 2026 3beuml）。只移植正常
CAS 表单登录、票据回调、`get-index`/`get-datatmp` 与校验语义；不嵌入 Python、MCP 服务、
DPAPI 桌面设施或其他学校的接口。系统备份仍关闭，来源项目只读、未重绑、未删除。

以下是三类不同事实，不能互相替代：

1. **参考源码事实**：固定提交中的 `timetable_protocol.py`、`timetable_service.py`、
   `timetable_tools.py`、`timetable_auth.py`、`auto_auth/cas.py` 与
   `auto_auth/providers/timetable.py` 给出上述协议形状、周日起算、ISO weekday 和严格错误语义；
   合成 fixture 只用于验证解析器。
2. **实际认证/数据验证**：2026-11-03 在 Android 36 模拟器上以用户明确授权的本人账号完成
   一次正常 CAS 登录和单周只读查询，页面显示周网格/今日课程，并在断网后重开显示已成功缓存。
   验证只读取本人课表，没有预约、报名、签到、充值或其他写操作；未在文档保留账号、密码、
   Cookie、票据或课程原文。Android 成功不等于 Python 或桌面浏览器成功，也不等于所有设备/网络
   条件可用。
3. **正式授权**：用户表示已与学校取得联系；这不构成官方客户端身份、统一认证接入资格或
   全量接口许可。应用仍按非官方工具描述，正式 API/授权到位前不扩大接口范围。

## 图书馆/空间六入口研究边界（2026-11-03）

用户标定的六个入口（唐岛湾座位、唐岛湾东馆研讨间、古镇口东区座位/研讨间、求是图书馆
座位/研讨间）已做公开前端与入口研究，见
[六入口接口研究](../research/图书馆与空间预约六入口接口研究-20261103.md)。边界按以下事实分开：

1. **公开前端事实**：`libseat`/`nspace` 的公开 JS 与公开配置给出了 CAS 入口、业务 token
   兑换和主要 API 路径；`office.chaoxing.com` 的 seat/seatengine 入口当前跳到
   passport2 登录，`reserve.chaoxing.com` 的裸 URL 在无租户/会话上下文时返回 303。
2. **现有页面事实**：求是 `reservepc` 已在用户现有 Edge 正常加载“研讨室列表”和
   A301、A402–A404、A501–A505；地址栏带 `reserveId/resvAppId/enc/fidEnc/uid/wfwEnc/code/state`
   等上下文（值不记录）。因此无 Cookie 的 302/303 不能说明现有会话不可用。
3. **实际 HAR**：2026-11-03 取得用户授权的六份只读 HAR（libseat、nspace、seat、
   seatengine、reservepc 两租户）。libseat 已确认 filters/floors/stats2/settings/
   announce 与空当前预约；nspace 已确认 venue/roomType/dates/roomList（6/11，2 页）；
   reservepc 两租户分别确认 8/23 个预约项、空 user list、loginStatus=true；seat/seatengine
   仅到入口配置、index、identity 和空 current/near，没有馆区/座位列表。
4. **认证边界**：六份 HAR 都没有 CAS/passport 登录跳转、token 获取或写请求；它们只
   证明已授权页面的只读请求，不能证明端到端统一认证。本机 Edge 没有 CDP 调试端点，
   为避免破坏现有会话，未重启 Edge 或修改调试配置。UPC-MCP 2026-10-31 的 `libseat`
   只读查询属于既有历史证据，不等于本轮重新验证。
5. **当前 Android 实现**：M4 已覆盖 `libseat` 统一认证、本人校验与既有会话迁移。M5 后续
   在首页“图书馆”统一入口中保留 libseat，并新增 nspace 独立 CAS/token、本人校验和原生只读
   馆区/类型/日期/房间分页；nspace token 只存内存，不与 seat token 混用。nspace 真实登录
   尚未验收；Chaoxing seat/seatengine 只提供官方浏览器入口；reservepc 两租户仍缺稳定入口
   上下文，统一页明确标注“待入口”。六入口矩阵与阻塞见
   [M5 图书馆六入口](../m5/图书馆六入口.md)。

入口目录见 [official-entrypoints.json](official-entrypoints.json)，用途为开发资料，不是应用运行时 API 配置。各功能实际能力以源码与 [验证记录](../CHANGELOG.md) 为准；入口返回 HTTP 200 不等于登录或业务完成。
