# UPC 当前服务来源

目标学校：中国石油大学（华东）。本表仅记录稳定、不含个人参数的学校地址；不保存实际账号、会话、票据或查询结果。

| 服务 | 学校入口 / 数据来源 | 当前接入 |
| --- | --- | --- |
| 空闲教室 | [学校查询页](https://app.upc.edu.cn/freeclass/wap/default/all) | 原生查询与分组网格；两校区 |
| 唐岛湾剩余电量 | [学校电量页](http://dfcz.upc.edu.cn/ShiYou/Default.aspx) | 原生按楼号、房间号查询 |
| 古镇口电费 | [学校电费页](https://gzkdf.upc.edu.cn/acmswx/index.aspx) | 外部页面；证书或网络异常时不绕过校验 |
| 图书馆座位 | [座位预约系统](https://libspace.upc.edu.cn/libseat/) | 官方统一认证后原生查询、预约与取消 |
| 校园卡余额 | `http://jhzf.upc.edu.cn:20081/wechat/callinterface/getCardInfo.html` | 本人学号 POST 查询，余额字段按分解析 |

校园卡余额页 `/wechat/query/balance.html` 与原生余额接口不是同一入口流程，裸页面可能提示令牌无效。当前轻量版不包含平台登录或流水。

入口目录见 [official-entrypoints.json](official-entrypoints.json)，用途为开发资料，不是应用运行时 API 配置。各功能实际能力以源码与 [验证记录](../CHANGELOG.md) 为准；入口返回 HTTP 200 不等于登录或业务完成。
