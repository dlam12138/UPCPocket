# UPC 当前服务来源

目标学校：中国石油大学（华东）。本表仅记录稳定、不含个人参数的学校地址；不保存实际账号、会话、票据或查询结果。

| 服务 | 学校入口 / 数据来源 | 当前接入 |
| --- | --- | --- |
| 空闲教室 | [学校查询页](https://app.upc.edu.cn/freeclass/wap/default/all) | 原生查询与分组网格；两校区 |
| 唐岛湾剩余电量 | [学校电量页](http://dfcz.upc.edu.cn/ShiYou/Default.aspx) | 原生按楼号、房间号查询 |
| 古镇口电费 | [学校电费页](https://gzkdf.upc.edu.cn/acmswx/index.aspx) | 外部页面；证书或网络异常时不绕过校验 |
| 图书馆座位 | [座位预约系统](https://libspace.upc.edu.cn/libseat/) | 官方统一认证后原生查询、预约与取消 |
| 校园卡余额 | `http://jhzf.upc.edu.cn:20081/wechat/callinterface/getCardInfo.html` | 本人学号 POST 查询，余额字段按分解析 |
| 课表 | [课表页](https://app.upc.edu.cn/site/weekschedule/index) | 正常 CAS 登录后原生只读查询、周网格、今日课程与已成功周离线缓存 |

校园卡余额页 `/wechat/query/balance.html` 与原生余额接口不是同一入口流程，裸页面可能提示令牌无效。当前轻量版不包含平台登录或流水。

## 课表来源与验证边界

课表协议、认证流程和严格解析参考本地 [UPC-MCP](https://github.com/dlam12138/UPC-MCP) 固定提交
`948f5f21ad7a12fd94b53403a07ac867209f7700`（MIT，Copyright (c) 2026 3beuml）。只移植正常
CAS 表单登录、票据回调、`get-index`/`get-datatmp` 与校验语义；不嵌入 Python、MCP 服务、
DPAPI 桌面设施或其他学校的接口。系统备份仍关闭，来源项目只读、未重绑、未删除。

以下是三类不同事实，不能互相替代：

1. **参考源码事实**：固定提交中的 `timetable_protocol.py`、`timetable_service.py`、
   `timetable_tools.py`、`timetable_auth.py`、`auto_auth/cas.py` 与
   `auto_auth/providers/timetable.py` 给出上述协议形状、周日起算、ISO weekday 和严格错误语义；
   合成 fixture 只用于验证解析器。
2. **实际认证/数据验证**：2026-11-03 在 Android 36 模拟器上以用户明确授权的本人账号完成
   一次正常 CAS 登录和单周只读查询，页面显示周网格/今日课程，并在断网后重开显示已成功缓存。
   验证只读取本人课表，没有预约、报名、签到、充值或其他写操作；未在文档保留账号、密码、
   Cookie、票据或课程原文。Android 成功不等于 Python 或桌面浏览器成功，也不等于所有设备/网络
   条件可用。
3. **正式授权**：用户表示已与学校取得联系；这不构成官方客户端身份、统一认证接入资格或
   全量接口许可。应用仍按非官方工具描述，正式 API/授权到位前不扩大接口范围。

入口目录见 [official-entrypoints.json](official-entrypoints.json)，用途为开发资料，不是应用运行时 API 配置。各功能实际能力以源码与 [验证记录](../CHANGELOG.md) 为准；入口返回 HTTP 200 不等于登录或业务完成。
