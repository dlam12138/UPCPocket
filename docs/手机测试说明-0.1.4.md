这是一个**预发行**包：唐岛湾电费已经用真实学校数据跑通；校园卡与图书馆要你在自己手机上登录一次才能算验证。

## 一、唐岛湾电费（不需要账号，应该一定能出数）

1. 更多 → 校园服务 → 「宿舍电费 · 唐岛湾」→ **在应用中查询剩余电量**。
2. 直接点「查询剩余电量」：应显示楼号列表已加载（默认 `01号楼(1)`）。
3. 填一个你确定的房间号（例如 `1101`）→ 查询。
4. 预期：显示「xx.xx 度」+「楼号 · 房间号」+「系统编号」+ 读取时间。
5. 再故意填一个短号（例如 `101`）：应该出现**两三个候选**让你选，而**不是**直接给一个电量。
   ——上一次版本在这里会把别人的电量当成你的，请特意试一下。

对照：用手机浏览器打开 `http://dfcz.upc.edu.cn/ShiYou/Default.aspx`，选同样的楼号与房间号，数值应一致。

## 二、校园卡余额（需要你登录，最重要）

1. 更多 → 打开「记住学校登录」。
2. 校园服务 →「校园卡余额」→「登录学校统一认证」。
3. 在出现的学校页面里自己登录（我不需要、也不会拿到你的密码）。
4. 登录成功后页面会自动关闭，回到余额页：
   - 成功：显示卡余额（元）、待圈存、账号打码后四位、口径与读取时间。
   - 失败：请把**这句话**发我 —— 它会区分“令牌无效 / 这次连不上 / 学校没返回数据”，
     我不需要你的截图、Cookie 或任何余额数字。
5. 杀掉 App 再打开 → 校园服务 →「校园卡余额」：应显示「内存中（已登录）」并能直接查到，
   不需要重新登录。
6. 退出：余额页「退出校园卡」，再进来应回到“需要登录”，且**不影响**图书馆与课表。

对照：学校微信企业号「校园卡服务大厅」里的卡余额，应与你看到的一致。

如果第 3 步的学校页面打不开（白页 / 连接被重置），请顺便告诉我：你在**手机流量**下重试是否也一样。
模拟器上这个域名连不上，但同一网络下电脑能连，需要确认真机是不是也这样。

## 三、课表（需要你登录）

导入 →「登录并同步学校课表」→ 官方登录 → 选学期 → 看第一周预览是否合理 → 确认写入。
重点看：是不是**整学期**都同步了（不是只有一周）、重复同步不会翻倍、重启后还能同步不用重登。

## 四、图书馆（需要你登录）

图书馆座位 →「使用学校统一认证登录」→ 回来后应能看到馆区/日期/座位。
预约与取消都只在你点确认后才发请求；如果它说“结果待确认”，请去学校页面核对后再回来刷新。

## 五、空教室（不需要账号）

校园服务 → 空闲教室 → 选校区/日期/节次 → 查询。应显示“可用 N 间 / 共 M 间”和查询时间。
