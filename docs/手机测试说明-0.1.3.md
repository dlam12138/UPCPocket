签名：与 0.1.1 / 0.1.2 相同的 debug 证书 → **直接覆盖安装，不要卸载**（卸载会丢本地课表）。

## 先确认升级

1. 覆盖安装后打开 App，确认原来的自定义日程、课程、节次时间仍在。
2. 「今天」页与桌面组件能正常显示。

## 课表同步（需要本人账号）

1. 课表页 →「导入」→「登录并同步学校课表」。
2. 在学校官方页面完成本人登录（不要在聊天里发送账号、密码、Cookie 或 token）。
3. 登录后应自动出现学期列表；默认选中学校当前学期，可改选。
4. 点「开始读取整学期」：串行逐周读取，任一周失败会停止且提示“没有写入”。
5. 预览里核对：学期、周范围、课程/时段数；**第 1 周周一日期**是否合理（可改）；
   如果是空学期，需要勾选确认才会替换。
6. 确认写入后：课表出现同步课程；点课程块可看详情；「今天」页与组件一致。
7. 再同步同一学期一次：不应出现重复课程；自定义日程与显示覆盖应保留。
8. 断网后再同步：应失败且旧课表不变。

> 首次真实运行重点看“学期/周数/第一周课表”是否正确。如果学校返回结构与 App 预期不同，
> 应显示“格式已变化/缺少 classes”等错误，而不是写入一份错课表；请把**报错文字**（不含个人信息）反馈。

## 图书馆（需要本人账号）

1. 「更多 → 校园服务 → 图书馆座位预约」→ 在应用内进入 → 统一认证登录。
2. 检查馆区、日期、房间、座位图、开始/结束时间是否来自学校真实返回。
3. 预约必须由本人明确点“确认提交”。提交后看「我的预约」是否出现**同一座位 + 完整日期时段**；
   没出现时 App 应显示“结果待确认”，不要重复提交。
4. 取消同样由本人点击；取消后刷新失败时列表应保留并标“待确认”，不能变成“没有预约”。
5. 「更多 → 学校登录」：打开/关闭“记住学校登录”，再点“退出学校登录”，确认会清理；重启后若记得登录，
   打开图书馆应能验证会话或明确要求重登。

## 空闲教室（无需账号）

「更多 → 校园服务 → 空闲教室」：选校区、日期、节次，查询；应显示查询时间与“可用/共”数量。
本轮模拟器复测：唐岛湾 2026-10-27 第 1、2 节，可用 110 / 216。

## 微信（仅备用）

当前没有正式 AppID 与已验证的微信直达能力。按钮只提供复制/分享到微信；
成功打开微信首页不等于进入学校目标服务。不要把它当作余额或课表已打通。

## 仍需你确认的边界

- 电费/校园卡余额：App 不显示（没有取得可用的本人只读数据链），不提供充值。
- 微信直达：未验证。
- 真实预约/取消：只应由你本人操作；App 不自动重试或抢座。
