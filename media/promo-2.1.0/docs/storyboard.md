# 分镜与时间线 · 《从早八到晚自习》

UPC Pocket 2.1.0 功能预览片。1920×1080、30 fps、5580 帧、186.00 秒；13 场、38 段旁白。旁白、烧录字幕、SRT 和配音位置由同一份 segment 时间线驱动。

> 画面依据 [导演分镜](../../../docs/releases/2.1.0-promo-storyboard.md) 制作。本页时间码取自成片时间线。

## 时间线机制

```text
vo-script.json (13 场 / 38 段 + pre/post/gap)
        │
        ├── make_vo.py ──► vo/<id>.mp3 + vo-durations.json
        │
        └── build_timeline.py ──► src/timeline.generated.json
                                      │
                    ┌─────────────────┼─────────────────┐
                    ▼                 ▼                 ▼
              Promo.tsx 场景      Captions.tsx       make_srt.py
              AudioTrack.tsx     烧录字幕            SRT
```

- 每个 segment 的 `duration` 由实测旁白 MP3 时长换算为帧（四舍五入，至少 1 帧）。
- 场与场之间没有重叠；每场由 `SceneShell` 在首 13 帧淡入、末 11 帧淡出，背景纸色保持连续，视觉上接近柔和溶解。
- 转场音效在每场开始前 4 帧进入（`AudioTrack.tsx` 的 `SCENES.slice(1).map(s => s.from - 4)`）。
- 字幕位于画面底部左侧，默认 `left:120 / bottom:82 / width:860`，字号 31；每段旁白按 `lines` 换行。
- SRT 末条为 03:00.567–03:03.033；03:03–03:06 是无声结尾卡。

- 原创 BGM 由 `scripts/build_audio.py` 用正弦/噪声合成，188.00 秒，混音音量 0.17；5 个原创 UI 音效：`impact-low`、`whoosh-soft`、`pop`、`chime`、`tick-ui`。
- 转场使用 `whoosh-soft`，首页固定、待办完成、组件出现和结尾使用 `pop`/`chime`；无第三方采样。
- 烧录字幕与 SRT 的文本、换行、起止帧完全一致；SRT 只有文本，不含样式。
