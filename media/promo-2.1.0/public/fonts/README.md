# Noto Sans SC · 版权与许可

本目录的 `NotoSansSC.ttf` 用于 Remotion 渲染时加载中文字体（`PromoSC`），不随 Android 应用打包。

- 字体名称：Noto Sans SC
- 字体版本：2.04（字体 name 表记录为 `Version 2.04;241114210130;non-release`）
- 版权声明（字体 name 表原文）：© 2014-2021 Adobe (http://www.adobe.com/), with Reserved Font Name 'Source'.
- 许可：SIL Open Font License 1.1，完整文本见同目录 [OFL.txt](OFL.txt)。
- 来源：作为单一 TTF 字体文件引入，工程未对字体做子集化或字形修改。

`OFL.txt` 是 SIL 提供的通用许可证文本，其开头的版权占位行不是本字体的版权声明；本文件补记字体自身 name 表中的版权信息，便于分发时保留归属。若后续替换字体，请同时替换本说明与 `OFL.txt` 并核对新字体的许可证。
